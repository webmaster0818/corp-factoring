日本政策金融公庫の融資は、個人事業主も利用できます。

民間の銀行融資やビジネスローンと比べて**低金利（年0.3%〜3%）**であり、**無担保・無保証人**で利用できる制度もあります。

日本政策金融公庫は、**[個人事業主の資金調達](/articles/article-kojin-shikin-chotatsu/)において最初に検討すべき金融機関**です。

この記事では、日本政策金融公庫の融資制度・審査基準・必要書類・申込手順を、**開業の段階別に解説**します。

## 日本政策金融公庫の概要

日本政策金融公庫（略称: 日本公庫・JFC）は、**政府が100%出資する政策金融機関**です。民間金融機関では対応が難しい創業者や、中小企業・個人事業主への融資を行っています。

**民間銀行との違い:**

| 項目 | 日本政策金融公庫 | 民間銀行 |
|------|--------------|--------|
| 金利 | 年0.3〜3.0% | 年1〜4% |
| 審査の難易度 | 中（創業者への対応に柔軟） | 高（実績を重視） |
| 担保・保証人 | 原則不要の制度あり | 必要な場合が多い |
| 審査期間 | 2〜3週間 | 2〜4週間 |
| 開業前の融資 | 可能 | ほぼ不可能 |
| 赤字への対応 | 柔軟 | 厳しい |

## 個人事業主が利用できる融資制度一覧

### 1. 新規開業・スタートアップ支援資金【開業前〜7年以内】

2024年に旧「新創業融資制度」から移行した制度で、開業前でも利用できます。

| 項目 | 内容 |
|------|------|
| 対象 | 新たに事業を始める方、または開業後おおむね7年以内の方 |
| 融資限度額 | **7,200万円**（うち運転資金4,800万円） |
| 金利 | 基準利率（年0.3%〜3.0%程度） |
| 返済期間 | 設備資金20年以内 / 運転資金10年以内 |
| 担保・保証人 | **原則不要** |
| 自己資金要件 | **撤廃（2024年〜）** ただし、自己資金がある方が審査では有利 |

2024年の制度改正の主な内容は、次のとおりです。
- 自己資金要件が撤廃された（以前は1/10以上が必要だった）
- 返済期間が延長された
- より利用しやすい制度に改められた

### 2. 一般貸付【業歴を問わず】

最も基本的な融資制度です。業歴や業種を問わず、幅広く利用できます。

| 項目 | 内容 |
|------|------|
| 対象 | ほとんどの業種の事業者 |
| 融資限度額 | **4,800万円**（運転資金・設備資金） |
| 金利 | 基準利率 |
| 返済期間 | 設備資金10年以内 / 運転資金7年以内 |
| 担保・保証人 | 応相談 |

### 3. マル経融資（小規模事業者経営改善資金）

商工会議所・商工会の推薦を受けて利用する融資制度です。

| 項目 | 内容 |
|------|------|
| 対象 | 商工会議所の経営指導を受けている小規模事業者 |
| 融資限度額 | **2,000万円** |
| 金利 | **特別利率（基準利率より低い）** |
| 担保・保証人 | **不要** |
| 条件 | 業歴1年以上、商工会議所の推薦が必要 |

**メリット:** 金利が低く、無担保・無保証人で利用できます。
**デメリット:** 商工会議所の推薦が必要です（3〜6ヶ月の経営指導を受ける必要があります）。

## 【段階別】適した融資制度

### 開業前の方

**→ 新規開業・スタートアップ支援資金**

開業前から利用できる公的融資制度です。事業計画書と自己資金が、審査の重要なポイントとなります。

**準備するもの:**
- 創業計画書（日本公庫のテンプレートあり）
- 自己資金を証明する通帳
- 事業に関する経験・スキルの証明

### 開業1年未満の方

**→ 新規開業・スタートアップ支援資金**

確定申告の前でも利用できます。売上の実績が少なくても、事業計画書の内容で審査されます。

### 開業1年以上の方

**→ 一般貸付またはマル経融資**

確定申告書の実績で審査されます。黒字であれば、審査に通る可能性は高くなります。商工会議所に加入している場合は、マル経融資が有利です。

### 開業3年以上で実績がある方

**→ 一般貸付（増額も可能）**

過去の融資の返済実績があれば、追加の融資や増額を受けやすくなります。

## 審査で確認される5つのポイント

### 1. 事業計画書の具体性【最重要】

**審査担当者は、「この事業で返済できるか」を判断します。**

具体的に記載すべき内容:
- **事業の概要:** どのような方法で収益を得るのか
- **市場分析:** 対象とする顧客は誰か、市場規模はどの程度か
- **売上計画:** 月次の売上予測と根拠
- **収支計画:** 経費・利益・返済原資の見通し
- **資金使途:** 借入金を何に使うか（具体的な内訳）

**不十分な例:** 「Webデザインの仕事をして収益を得ます」
**適切な例:** 「月間3件のWebサイト制作を受注（1件30万円×3=月90万円）。根拠: 前職のクライアントA社から月1件の継続受注が確定済み。営業活動で月2件の新規獲得を見込む（過去の受注率30%×月7件の提案=2.1件）」

### 2. 自己資金の額

2024年の制度改正で自己資金要件は撤廃されましたが、**自己資金が多いほど審査では有利**です。

**目安:**
- 融資額の1/3以上: 非常に有利
- 融資額の1/4〜1/3: 有利
- 融資額の1/10以上: 標準
- 自己資金なし: 不利（ただし不可ではない）

なお、申込の直前に親族から一括で入金された、いわゆる「見せ金」は審査で判明します。通帳の6ヶ月〜1年分が確認されるため、継続的に貯めた自己資金であることが重要です。

### 3. 信用情報

CIC・JICCの信用情報が確認されます。以下に該当する場合、審査は厳しくなります。

- クレジットカードの延滞
- ローンの返済遅延
- 債務整理・自己破産の履歴
- 税金の滞納
- 公共料金の未払い

**対策:** 事前にCIC（https://www.cic.co.jp）で、自身の信用情報を確認しておいてください（手数料500円〜1,000円）。

### 4. 事業経験

融資を受ける業種での経験があると、審査で有利になります。たとえば、飲食店を開業する場合、飲食業界での勤務経験が3年以上あると、評価が高くなります。

### 5. 資金の使い道の妥当性

「1,000万円を借りたい」と金額のみを示すのではなく、**具体的な見積書や計画書**を添えて、その金額が必要な理由を説明してください。

## 申込から入金までの流れ（5つのステップ）

### STEP1: 相談（無料）

まずは日本公庫に相談します。電話（0120-154-505）、オンライン、窓口のいずれでも対応しています。

事前相談の段階で、「必要書類」「審査のポイント」「自身のケースで融資が可能か」を確認できます。相談は無料です。

### STEP2: 申込

インターネットまたは窓口で申し込み、必要書類をすべて提出します。

インターネットでの申込は、24時間365日受け付けています。書類はPDFでアップロードできます。

### STEP3: 面談

日本公庫の担当者と面談し、事業計画書の内容について質問を受けます。

**主な質問の例:**
- この事業を始める理由
- 売上見込みの根拠
- 資金の使い道
- 返済の方法
- 事業が計画どおりに進まなかった場合の対応

面談では、数字を用いて具体的に回答することが重要です。意欲のみを伝えるのではなく、「月商80万円の根拠は〜」のように説明してください。

### STEP4: 審査（2〜3週間）

書類・面談の内容に基づいて審査が行われます。追加の書類を求められることもあります。

### STEP5: 融資実行

審査の通過後、契約書に署名すると融資が実行され、指定口座に振り込まれます。

**所要期間の合計: 申込から入金まで約3〜4週間**

## 審査に落ちる主な理由と対策

| 理由 | 対策 |
|------|------|
| 事業計画書の内容が曖昧 | 数字の根拠を具体的に記載する |
| 自己資金が少ない | 融資額の1/10以上を目安に貯める |
| 信用情報に問題がある | 事前にCICで確認し、延滞を解消する |
| 税金を滞納している | 分割納付などで解消してから申し込む |
| 資金使途が不明確 | 見積書を添付して具体的に説明する |
| 事業経験がない | 関連業務の経験・スキルを説明する |

## 審査に通らなかった場合の代替策

### 1. 6ヶ月後に再申請する

審査に通らなかった理由を改善したうえで、再度申し込みます。一般的に、6ヶ月程度の期間を空けることが目安です。

### 2. 信用金庫に相談する

信用金庫は地域密着型の金融機関で、個人事業主への融資にも積極的です。日本公庫より審査が柔軟な場合もあります。

### 3. [ファクタリング](/articles/article-factoring-kojin-jigyonushi/)で当面の資金を確保する

融資の審査を待つ間の「つなぎ資金」として、ファクタリングを利用する方法があります。

| サービス | 手数料 | 入金スピード | 特徴 |
|---------|--------|------------|------|
| ペイトナー | 10%固定 | 最短即日 | 信用情報に影響なし |
| QuQuMo | 1%〜 | 最短2時間 | 手数料の下限が低い |
| ビートレーディング | 2%〜 | 最短2時間 | 累計91,000社の実績 |

**ファクタリングは信用情報に影響しないため、日本公庫への再申請に影響しません。**

### 4. 補助金・助成金を活用する

返済不要の資金調達の方法です。小規模事業者持続化補助金（最大250万円）などを利用できる場合があります。

## よくある質問

### Q. 審査はどの程度厳しいですか？

**A. 民間銀行と比較して、審査に通りやすいといえます。** 日本公庫は政策金融機関として、民間金融機関が対応しにくい創業者や小規模事業者への融資を目的としています。ただし、事業計画書の完成度と自己資金は重要です。

### Q. いくらまで借りられますか？

**A. 制度により異なります。**
- 新規開業・スタートアップ支援資金: 最大7,200万円
- 一般貸付: 最大4,800万円
- マル経融資: 最大2,000万円

ただし、初めて融資を受ける個人事業主の場合、実際の借入額は300万〜1,000万円程度が一般的です。

### Q. 金利はどの程度ですか？

**A. 年0.3%〜3.0%程度です。** 制度・返済期間・担保の有無によって異なります。最新の金利は、日本公庫の公式サイトでご確認ください。

### Q. 開業届を提出していない場合は利用できませんか？

**A. 原則として、開業届の提出が必要です。** 未提出の場合は、税務署に提出してください。freeeやマネーフォワードのサービスを利用すると、無料で作成できます。

### Q. 返済できなくなった場合はどうなりますか？

**A. まずは日本公庫に相談してください。** 返済条件の変更（返済額の減額・返済期間の延長）に応じてもらえる場合があります。連絡をせずに滞納することは避けてください。

## まとめ

**日本政策金融公庫は、個人事業主の融資において最初に検討すべき選択肢です。**

- 金利: 年0.3%〜3%（民間の1/3以下）
- 担保・保証人: 原則不要
- 開業前でも利用できる
- 自己資金要件は撤廃（2024年〜）

**最初に取り組むべきこと:**
1. 日本公庫に無料で相談する（0120-154-505）
2. 創業計画書をダウンロードし、記入を始める
3. 通帳を整理する（自己資金の確認）

**急ぎの資金が必要な場合は、ファクタリング（最短即日）で当面の資金を確保しながら、並行して日本公庫の融資の手続きを進める方法をおすすめします。**
