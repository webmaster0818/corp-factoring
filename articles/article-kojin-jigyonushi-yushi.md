# 個人事業主の融資｜申込先別の必要書類・条件と売掛金で資金を作る方法の比較

**対策KW:** 個人事業主 融資
**メタdescription:** 個人事業主の融資は、日本政策金融公庫と自治体の制度融資が主な公的な申込先です。両者が公式に求める書類と条件を、申告・納税の状態別に整理し、確定申告書が2期そろわないときや急ぎのときに、請求書を売るファクタリングの書類とどう違うかを比べます。
**想定文字数:** 6,500字
**ステータス:** 下書き

---

個人事業主が事業資金を借りる主な公的な申込先は、日本政策金融公庫（国民生活事業）と、自治体の制度融資（信用保証協会の保証付きで金融機関から借りる）の二つで、どちらも原則として直近2期分の確定申告書を提出します。申告がまだ1期以下、納税に未納がある、数日以内に資金が要る、といった状況では使える手段が変わるため、自分の申告・納税の状態から申込先を選ぶのが近道です。

この記事は、制度の中身よりも「申込先ごとに何を出し、どんな条件があり、いつ決まるか」に絞って整理します。日本公庫の各制度の限度額や利率は[日本公庫の個人事業主向け融資の記事](/articles/article-jfc-kojin/)、自治体の制度融資の仕組みと費用は[制度融資の記事](/articles/article-seido-yuushi/)、赤字のときの制度は[赤字でも使える融資の記事](/articles/article-akaji-yuushi/)で扱っています。

## 公的な二つの申込先を書類と条件で比べる

次の表は、日本公庫の「[お手続きの流れ（国民生活事業）](https://www.jfc.go.jp/n/finance/flow/goriyou.html)」と、東京都の「[東京都中小企業制度融資](https://www.sangyo-rodo.metro.tokyo.lg.jp/chushou/kinyu/yuushi/yuushi)」（お申込み条件・必要書類のページ）に書かれている個人事業主向けの内容です。自治体の制度融資は、公式資料が詳しく公開されている東京都を例にしています（いずれも2026年11月16日確認）。

| 比べる点 | 日本公庫（国民生活事業） | 東京都の制度融資（例） |
|---|---|---|
| 申込みの窓口 | インターネット申込（24時間365日受付） | 取扱指定金融機関の融資窓口 |
| 事業の計画書 | はじめての方は創業計画書または企業概要書 | 融資メニューにより計画書などを追加 |
| 確定申告書 | 直近期と前期の2期分の一式（申込みの都度。1期のみの方は1期分、申告前の方は不要） | 所得税の確定申告書の写し（原則直近2期分） |
| 納税の確認 | 一覧に記載なし | 所得税又は事業税の納税の確認ができる書類 |
| 本人の確認 | 運転免許証・マイナンバーカード・パスポートのいずれか | 印鑑証明書（申込人のもの） |
| 税・保険料の条件 | お手続きの流れのページに記載なし | 事業税等の未申告・滞納や社会保険料の滞納がないこと（完納の見通しが立つ場合はこの限りではない） |
| 審査・決定 | 面談。決まるまで平均3週間程度（創業Q&A） | 東京信用保証協会が保証の諾否を判断し、金融機関が融資。確認した都の資料に日数の記載なし |
| 費用 | 利息（令和8年11月2日現在、無担保・2期終了の基準利率は年3.95〜5.35%） | 利息（上限あり）＋信用保証料（都が一部を補助） |

公庫は確定申告書について「確定申告書の表紙だけでなく、一式がご準備できているか」と注意しており、個人事業主の場合は「青色申告の方は青色申告決算書、いわゆる白色申告の方は収支内訳書を含みます」と書いています。個人事業主にとっては、決算書にあたる書類も確定申告書一式の中に入っているということです。

民間の銀行・信用金庫のプロパー融資やノンバンクのビジネスローンは、書類や条件を各社が個別に定めています。ノンバンクの比べ方は[個人事業主向けビジネスローンの記事](/articles/article-business-loan-kojin/)をご覧ください。

## 申告・納税の状態から申込先を選ぶ

上の公式資料の条件を、個人事業主の状態ごとに当てはめると次のようになります。

| あなたの状態 | 日本公庫 | 東京都の制度融資（例） |
|---|---|---|
| 開業前 | 創業計画書で申込み（確定申告書は不要） | 「創業」メニュー（都内で創業する具体的計画がある個人） |
| 開業後、まだ申告していない | 確定申告書の提出は不要。創業計画書で申込み | 「創業」メニュー（創業5年未満） |
| 申告を1期終えた | 1期分の確定申告書で申込み | 原則2期分。「創業」メニューの条件を確認 |
| 申告を2期以上終えた | 2期分の確定申告書（はじめての方は企業概要書も） | 2期分の確定申告書と納税の確認書類 |
| 事業税・社会保険料に滞納がある | お手続きの流れのページに条件の記載なし（審査で判断） | 申込条件で「滞納がないこと」（完納の見通しが立つ場合を除く） |

税務申告の期数は、公庫の利率にも関係します。公庫の金利表は「税務申告を2期終えている方」と「2期終えていない方」で利率を分けており、2期終えていない方には創業支援貸付利率特例制度（0.65%引下げ）も用意されています。

確定申告の内容と融資の関係は、[確定申告と融資の記事](/articles/article-kakuteishinkoku-yuushi/)で詳しく扱っています。

### 開業届の扱い

公庫のお手続きの流れのページに掲載されている個人事業主の必要書類には、開業届は入っていません。国税庁は開業届の提出時期を「事業の開始等の事実があった日の属する年分の確定申告期限までに提出してください」と案内しています（[A1-5 個人事業の開業届出・廃業届出等手続](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)）。

## 商工会議所・商工会の経営指導から広がる選択肢

公庫と東京都の制度には、商工会議所・商工会の経営指導を受けていることを条件にした優遇があります。どちらも小規模な個人事業主が使うことを想定した制度です。

| 制度 | 条件（公式の記載） | 内容 |
|---|---|---|
| 日本公庫 [マル経融資（小規模事業者経営改善資金）](https://www.jfc.go.jp/n/finance/search/kaizen_m.html) | 商工会議所、商工会又は都道府県商工会連合会の実施する経営指導を受けている小規模事業者（商工業者に限る）で、商工会議所等の長の推薦を受けた方 | 融資限度額2,000万円、返済期間10年以内（据置期間2年以内）、無担保・無保証人、特別利率F（令和8年11月2日現在 年2.95%） |
| 東京都 小口支援特例 | 「小口」の対象で、商工会議所・商工会の経営指導を直近1年以内に6か月以上複数回受けていることなど | 「小口」（融資限度額2,000万円）の利率より0.4%優遇 |

マル経融資は推薦が条件なので、申込みの前に地元の商工会議所・商工会で経営指導を受けることから始まります。公庫のお手続きの流れのページも、マル経融資は手続きや添付書類が異なる場合があると注記しています。

## 借りる以外の選択肢：売掛金を売るファクタリングの書類

取引先に請求書を出していて入金を待っている個人事業主は、借りる代わりに、その請求書（売掛金）を入金日前に売って現金化する方法もあります。ファクタリングは借入れではなく売掛金の売買で、必要書類も融資とは中身が違います。

当サイトの掲載社のうち、公式サイトで対象にフリーランスを明記している会社（ペイトナーは「個人事業主・一人法人」と表示）から、必要書類の一覧を公式に示している会社を抜き出し、一覧の書類の数が少ない順（同数は社名の五十音順）に並べました。評価や推奨の順位ではありません。

| 会社名 | 公式に記載された必要書類 | 確定申告書の扱い（公式表示） | 確認日 |
|---|---|---|---|
| [ビートレーディング](/companies/be-trading/) | 売掛金に関する書類（請求書等）、口座の入出金明細（2か月分）の2点 | 一覧に記載なし | 2026年10月31日 |
| [FREENANCE](/companies/freenance/) | 写真付き公的身分証（会員登録時）、請求書。入出金履歴などの審査エビデンスは任意 | 一覧に記載なし | 2026年10月31日 |
| [PayToday](/companies/paytoday/) | 必須は請求書と本人確認書類の2点（決算書・入出金明細は「必須ではない」と表記） | よくある質問で個人事業主は「確定申告書の提出は不要」 | 2026年11月1日 |
| [MSFJ](/companies/msfj/) | 請求書、本人確認書類、入出金のわかる通帳コピー（審査により追加書類の場合あり） | 一覧に記載なし | 2026年10月31日 |
| [買速](/companies/kaisoku/) | 個人事業主は本人確認書類・通帳のコピー・請求書の3点 | 一覧に記載なし | 2026年11月1日 |
| [QuQuMo](/companies/ququmo/) | 本人確認書類、保有する全銀行口座の入出金明細（直近3ヶ月分）、請求書 | 個人事業主は開業届又は青色・白色の確定申告書一式を提出 | 2026年11月12日 |
| [Chatwork 先払い](/companies/chatwork-sakibarai/) | 請求書、顔写真付き身分証明書、実態確認資料（サイトURLか口座入出金履歴） | 一覧に記載なし（決算書は不要と記載） | 2026年11月26日 |
| [ペイトナー](/companies/paytner/) | 請求書、本人確認書類（初回のみ）、直近3ヶ月分の入出金明細 | 一覧に記載なし（審査状況により追加書類の場合あり） | 2026年11月1日 |
| [ラボル](/companies/labol/) | 本人確認書類、請求書、取引を示すエビデンス（取引先とのメール等） | 一覧に記載なし | 2026年11月1日 |
| [OLTA](/companies/olta/) | 本人確認書類、請求書、事業用口座の直近4カ月分の入出金明細、財務書類 | 個人事業主は確定申告書第一表の控えと開業届 | 2026年10月31日 |
| [バイオン](/companies/bion/) | 本人確認書類、請求書、全銀行口座の入出金明細（3ヶ月分）、直近の決算書（発注書などは任意） | 個人事業主は確定申告書一式（1期済んでいない場合は試算表） | 2026年10月31日 |
| [プログレス](/companies/progress/) | 面談時に請求書・契約書など、登記簿謄本、印鑑証明、決算書、実印、身分証明書、入金口座・当座照合表（原本）、住民票 | 個人事業主の確定申告書の扱いは公式に記載なし | 2026年11月10日 |

## 融資とファクタリングを選ぶ基準

| 判断の材料 | 融資（公庫・制度融資）が合う | ファクタリングが合う |
|---|---|---|
| 必要な時期 | 数週間以上先 | 数日以内 |
| 必要な金額 | 売掛金の額を超える（設備・数か月分の運転資金） | 入金待ちの請求書の範囲内 |
| 申告の状態 | 2期分の申告がそろっている（または創業融資の対象） | 申告書がそろっていなくても、一覧に申告書を挙げていない会社がある |
| 費用 | 年利（公庫は無担保で年3.75〜5.35%の範囲の基準利率など） | 1回ごとの手数料（例：上の表のペイトナー・ラボルは一律10%） |
| 返済 | 月賦などで数年かけて返済 | 返済ではなく、売掛先からの入金で取引が終わる |

費用の水準は大きく違います。例：売掛金100万円を手数料10%で売ると費用は10万円です。同じ90万円を年5%で1年借りた場合の利息は単純計算で4万5,000円で（仮定の計算）、ファクタリングは数十日分の資金化でもこれを上回ることがあります。時間に余裕があれば融資を、間に合わない支払いがあるときだけファクタリングを、という順番で考えると費用を抑えられます。手数料の年率換算は[掛け目と年率換算の記事](/articles/article-factoring-kakeme-nenritsu/)、融資への影響は[ファクタリングと銀行融資の関係の記事](/articles/article-factoring-ginkou-yuushi-eikyou/)で扱っています。

## 申し込む前に準備するもの

- **確定申告書一式（2期分）**：青色申告決算書または収支内訳書まで含めて。公庫は申込みの都度2期分が必要と案内しています
- **納税の確認ができる書類**：東京都の制度融資では個人の共通書類に含まれます
- **見積書**：設備資金を申し込む場合（公庫・東京都とも）
- **許認可証等**：許可・届出が必要な事業の場合（公庫）
- **入金待ちの請求書と通帳の入出金明細**：ファクタリングと比べる場合。多くの会社の必要書類の一覧に入っています

## よくある質問

**Q: 個人事業主が融資を申し込むとき、最初にどこへ相談すればよいですか？**
A: 日本公庫は事業資金相談ダイヤル（0120-154-505）や支店で、東京都の制度融資は東京都産業労働局金融課、東京信用保証協会の各支店、商工会議所・商工会などで相談を受け付けています。都外の方は事業所のある自治体の制度融資の窓口を確認してください。

**Q: 確定申告を1期しかしていなくても融資は受けられますか？**
A: 日本公庫は、税務申告が1期しか完了していない方は1期分の確定申告書を準備するよう案内しています。東京都の制度融資は原則2期分ですが、創業5年未満の方などが使える「創業」メニューがあります。審査の結果は申込みごとに判断されます。

**Q: 税金を滞納していると融資は受けられませんか？**
A: 東京都の制度融資の申込条件には、事業税等の未申告・滞納や社会保険料の滞納がないことが挙げられています（完納の見通しが立つ場合はこの限りではないと記載）。日本公庫のお手続きの流れのページには、滞納についての条件は書かれていません。

**Q: マル経融資は個人事業主でも使えますか？**
A: 公庫の公式ページでは、対象を「商工会議所、商工会又は都道府県商工会連合会の実施する経営指導を受けている小規模事業者（商工業者に限る。）であって、商工会議所等の長の推薦を受けた方」としています。個人事業主でもこの条件に当たれば対象です。無担保・無保証人で、融資限度額は2,000万円です。

**Q: 融資とファクタリングはどちらを先に検討すべきですか？**
A: 必要な時期が数週間以上先で、売掛金を超える額が必要なら融資を先に検討します。数日以内に必要で、入金待ちの請求書がある場合はファクタリングと比べます。手数料は融資の利息より高くなりやすいため、継続的な資金不足は融資で手当てするのが基本です。
