介護報酬（介護給付費）は、サービスを提供した月の翌月10日までに国保連（国民健康保険団体連合会）へ請求し、その翌月に支払われます。東京都国保連の令和8年度の日程では、9月に提供したサービスの分（10月請求）が11月24日に支払われ、月末から入金まで55日あります。

介護報酬ファクタリングは、この国保連に請求した介護給付費の債権を、支払日の前に買い取ってもらう方法です。この記事では、法令と国保連の公表資料で入金の時期を確かめ、当サイトが掲載する59社のうち介護報酬の買取を公式サイトで示している20社の条件を、当サイトのデータから抜き出して比べます。

## 介護報酬が入金されるまで：法令と国保連の日程

### 請求先は国保連、期限は翌月10日

介護保険法は、市町村が事業者からの居宅介護サービス費の請求を審査したうえで支払うこと（41条9項）、その審査と支払の事務を国保連に委託できること（41条10項）を定めています。請求の期限は、厚生労働省令「介護給付費及び公費負担医療等に関する費用等の請求に関する命令」の3条1項が「各月分について翌月十日までに行わなければならない」と定めています（いずれもe-Gov法令検索・2026年11月16日確認）。

大阪府国保連の令和8年度のカレンダーは、介護給付費明細書等の受付を毎月1日から10日までとし、「11日以降の受付は行いませんのでご注意ください」と案内しています（大阪府国民健康保険団体連合会「受付日・支払日カレンダー」・2026年11月16日確認）。10日を過ぎると、その月の請求には乗りません。

### 支払日は都道府県の国保連ごとに決まる

東京都国保連が公表している令和8年度の介護給付費等の支払日は、次のとおりです（東京都国民健康保険団体連合会「令和8年度介護給付費等の支払日について」・2026年11月16日確認）。

| 請求月（サービス提供月の翌月） | 支払日 |
|---|---|
| 令和8年4月 | 5月25日（月） |
| 5月 | 6月23日（火） |
| 6月 | 7月23日（木） |
| 7月 | 8月24日（月） |
| 8月 | 9月24日（木） |
| 9月 | 10月23日（金） |
| 10月 | 11月24日（火） |
| 11月 | 12月23日（水） |
| 12月 | 令和9年1月25日（月） |
| 令和9年1月 | 2月24日（水） |
| 2月 | 3月23日（火） |
| 3月 | 4月23日（金） |

同じ資料は、支払日を「原則２３日（土・日・祝日に当たる場合は直後の平日。ただし、支払日が２６日以降の日に当たる場合は２３日の直前の平日）」と説明しています。同じ東京都国保連でも、障害福祉サービス費等の支払日は原則15日で、介護とは日が異なります（[障害福祉サービスの報酬のファクタリング](/articles/article-factoring-shougai-fukushi/)）。

**例（東京都の事業所・2026年9月のサービス提供分）：**
9月30日に提供月が終わる → 10月1日〜10日に国保連へ請求 → 11月24日に支払。人件費を9月末と10月末に払う場合、9月分の介護報酬が入るのは2回分の給与の後です。

所在地がほかの道府県の場合は、その国保連の公表資料で支払日を確かめてください。北海道国保連も「令和８年度の支払日（予定）(介護)」を公表しています（2026年11月16日確認）。

### 国保連に請求できるのは「保険給付の分」だけ

介護保険法41条4項は、居宅介護サービス費の額を、基準で算定した費用の「百分の九十に相当する額」としています。一定以上の所得がある第1号被保険者は、49条の2により「百分の八十」または「百分の七十」に読み替えられます（e-Gov法令検索・2026年11月16日確認）。残りの利用者負担の分は、国保連ではなく利用者本人に請求します。

また41条1項は、通所介護や短期入所などの費用のうち、食事の提供に要する費用、滞在に要する費用その他の日常生活に要する費用（厚生労働省令で定めるもの）を居宅介護サービス費から除いています。これらも利用者に請求する分です。

| 売上の区分 | 請求先 | 支払の時期 | ファクタリングでの扱い |
|---|---|---|---|
| 保険給付の分（原則9割・所得により8割または7割） | 国保連 | 国保連ごとの支払日（東京都は原則23日） | 介護報酬ファクタリングの対象。下の20社の表 |
| 利用者負担の分（1〜3割） | 利用者本人 | 事業所と利用者の契約による | 売掛先が個人の債権。扱いは会社ごとに異なる（[売掛先が個人の請求書](/articles/article-factoring-urikakesaki-kojin/)） |
| 食費・滞在費など | 利用者本人 | 同上 | 同上 |

## 買取割合と手数料から手元に入る額を計算する（仮定の例）

介護報酬に特化したサービスには、請求額の全額ではなく一部（80〜95%など）を買い取る、または先に払う形を公式に示している会社があり、カイポケ早期入金は残りの20%を後日支払うとしています。手元に先に入る額は「請求額 × 前払いの割合 − 手数料」です。

**例：国保連への請求額300万円・前払いの割合80%・手数料は前払い額の1%と仮定した場合**

- 先に入る額：300万円 × 80% = 240万円
- 手数料：240万円 × 1% = 2万4,000円
- 先に手元に入る額：240万円 − 2万4,000円 = 237万6,000円
- 残りの60万円：国保連の支払日の後に精算（審査で減額があった場合の扱いは契約による）

手数料の計算の元が「請求額」か「前払い額」か、初回手数料や月額費用がかかるかは、会社ごとに異なります（上の表のカイポケ早期入金・FPSメディカルの例）。月率や1日あたりの率で表示している会社の率を比べるときは、[掛け目と手数料の年率換算](/articles/article-factoring-kakeme-nenritsu/)の計算方法を使ってください。

## 申し込む前に確かめること

1. **所在地の国保連の支払日**：東京都は原則23日ですが、道府県によって日が違います。支払日から逆算して、給与日に間に合うかを確かめます
2. **請求を10日までに出せるか**：期限を過ぎた分はその月の支払いに乗らないため、ファクタリングの対象になる請求額も変わります
3. **国保連への通知の方式**：特化型の5社は、当サイトのデータでは国保連などへの通知や連名の手続きを行う方式です。2社間を示している一般の会社と、手続きと手数料を比べます（[2社間と3社間の違い](/articles/article-factoring-2sha-3sha/)）
4. **法人か個人事業主か**：三菱ＵＦＪファクターの介護報酬は法人の介護事業所が対象、FPSメディカルは個人事業主も可など、対象が会社ごとに違います
5. **利用者負担・食費などの分を分けて考える**：国保連に請求しない部分は、介護報酬ファクタリングの対象に含まれません

訪問看護ステーションで医療保険分と介護保険分の両方がある場合は、[訪問看護ステーションの報酬を早く受け取る方法](/articles/article-factoring-houmon-kango/)、診療報酬は[診療報酬ファクタリング](/articles/article-factoring-iryou/)で入金の時期を整理しています。

## よくある質問

**Q: 介護報酬は、サービス提供から何日後に入金されますか？**
A: 各月分を翌月10日までに国保連へ請求し（請求命令3条1項）、支払日は国保連ごとに決まります。東京都国保連の令和8年度の日程では、9月提供分（10月請求）の支払日は11月24日で、提供月の末日から55日後です（2026年11月16日確認）。

**Q: 開設したばかりの事業所でも使えますか？**
A: 当サイトのデータでは、リコーリースが新設法人も可、カイポケ早期入金が立ち上げたばかりの事業所も可としています（2026年11月6日・10月31日確認）。最初の請求を国保連に出した後の請求額が対象になるため、開設月の分の入金時期は上の日程で確かめてください。

**Q: 利用者負担の1割分もまとめて売れますか？**
A: 利用者負担の分は国保連ではなく利用者本人への請求で、介護報酬ファクタリングの対象の外です。売掛先が個人の債権を扱うかは会社ごとに異なり、[売掛先が個人の請求書](/articles/article-factoring-urikakesaki-kojin/)で各社の記載を整理しています。

**Q: 障害福祉サービスの給付費も同じ会社で扱えますか？**
A: リコーリースは指定障害サービスも可、メドレー早期資金サポートは障がい福祉事業所も対象、FPSメディカルは障害福祉施設も対象と、当サイトのデータにあります（2026年11月6日・10日確認）。障害福祉の支払日は東京都国保連では原則15日で、介護とは異なります。
