# 国際ファクタリングとは｜仕組み・利用法・対応会社【2026年】

**想定文字数:** 4,800字
**ステータス:** 下書き

---

海外取引の売掛金を早期に回収したい場合や、信用面に不安のある海外の取引先に対応したい場合の手段として、国際ファクタリングが注目されています。国際取引の増加に伴い、海外取引のリスク回避と資金繰りの改善に活用されています。

この記事では、国際ファクタリングの仕組み、種類、メリット・デメリット、対応している会社を解説します。

---

## 国際ファクタリングとは

### 定義
輸出取引における**海外の取引先（輸入者）に対する売掛金**を、ファクタリング会社が買い取るサービスです。

### 国内ファクタリングとの違い

| 項目 | 国内ファクタリング | 国際ファクタリング |
|------|----------------|----------------|
| 取引対象 | 国内売掛金 | 海外売掛金 |
| 通貨 | 円 | 外貨（USD、EUR等） |
| 与信評価 | 国内信用情報 | 海外信用情報 |
| 関与機関 | 1社 | 輸出側と輸入側の2社が協働 |
| 対象企業 | 中小〜大手 | 主に大手・中堅 |
| 手数料 | 2〜18% | 1〜5%（銀行系） |

---

## 国際ファクタリングの主要な種類

### 1. 2当事者制（2-Factor System）

#### 仕組み
1. 輸出者（日本企業）が海外の取引先に製品を販売する
2. 国内のExport Factor（輸出ファクター）に売掛金を譲渡する
3. Export Factorが、海外のImport Factor（輸入ファクター）と提携する
4. Import Factorが、海外の取引先の与信を判断する
5. Import Factorが、海外の取引先から回収する

### 2. ストレート輸出ファクタリング
- 国内のファクタリング会社が、海外の取引先から直接回収する
- 大手の国際ファクタリング会社のみが対応

### 3. リバース・国際ファクタリング
- 輸入者（海外の取引先）が主導する
- サプライチェーンファイナンスの一形態
- 詳しくは[リバースファクタリング](/articles/article-factoring-reverse/)をご覧ください

## 国際ファクタリングのメリット

### 1. 海外の与信リスクの回避
- 海外の取引先の倒産リスクを、ファクタリング会社が負担する
- 為替変動のリスクもヘッジが可能（オプション）

### 2. 早期の資金化
- 海外取引のサイトは90〜180日が一般的
- ファクタリングにより早期に資金化できる

### 3. 取り立て・回収業務の代行
- 海外の取引先への督促を、Import Factorが代行する
- 言語・法制度の違いへの対応が不要になる

### 4. L/C（信用状）の代替手段
- L/Cより手続きが簡便
- 銀行手数料より安いケースもある

### 5. 輸出与信枠の拡大
- 銀行の輸出与信枠を使わずに資金を調達できる
- 既存の銀行取引の枠を温存できる

## デメリット・注意点

### 1. 対応する国・通貨が限定される
- 主要国（米国、EU、中国、韓国等）が中心
- 新興国には対応していない場合が多い

### 2. 手数料の水準
- 銀行系で1〜5%、独立系で3〜10%
- 国内の2社間ファクタリングより安いケースが多い

### 3. 申込の手続きが複雑
- 海外取引の契約書・関税書類等の準備が必要
- 申込から契約まで1ヶ月程度かかる

### 4. 大企業が中心
- 取り扱う会社が、大手金融機関に集中している
- 中小企業にとっては利用のハードルが高い

### 5. 売掛先（海外の取引先）への通知が必須
- 国際ファクタリングは3社間が前提
- 2社間ファクタリングの形態はない

## 国際ファクタリングの利用に適している業種

### 製造業(輸出メーカー)
自動車部品、機械、電子部品等の輸出です。

### 商社・卸売業
海外との貿易・輸出の仲介です。

### IT・SaaS事業
グローバルな顧客向けのサブスクリプション・ライセンスの販売です。

### 食品・農産物
輸出向けの食品・農産物の販売です。

### 海外建設業
プラント・大型工事の海外展開です。

## 国際ファクタリングの利用の流れ

### ステップ1：海外の取引先の与信審査
Import Factorが、海外の取引先の信用力を審査します（1〜2週間）。

### ステップ2：輸出取引の契約締結
通常の輸出取引と同様に、契約書・売買条件を確定します。

### ステップ3：ファクタリング契約の締結
Export Factorと輸出者が、ファクタリング契約を締結します。

### ステップ4：商品の出荷・請求書の発行
輸出者が商品を出荷し、海外の取引先宛てに請求書を発行します。

### ステップ5：ファクタリング会社への売掛金の譲渡
請求書を提示し、手数料を差し引いた金額が入金されます。

### ステップ6:回収
Import Factorが、海外の取引先から期日どおりに回収します。

### ステップ7:精算
両Factor間で精算し、該当する場合は、輸出者に差額分が追加で入金されます。

## 国際ファクタリングと L/C（信用状）の比較

| 項目 | 国際ファクタリング | L/C(信用状) |
|------|----------------|-----------|
| 主導 | 輸出者 | 輸入者 |
| 与信リスク | ファクタリング会社が負担 | 銀行が保証 |
| 手続き | 比較的簡便 | 厳格な書類審査 |
| 手数料・料金 | 1〜10% | 銀行手数料0.1〜0.5% |
| 資金化のスピード | 即時〜数日 | 書類処理後、数日 |
| 為替リスク | ヘッジ可能 | 別途対応が必要 |
| 用途 | 継続取引向け | 単発・大口の取引向け |

L/Cと国際ファクタリングは併用も可能です。

## 為替リスクのヘッジとの組み合わせ

### 為替ヘッジの方法
1. **為替予約の同時実施**：ファクタリング契約時に為替予約を行う
2. **円建てのファクタリング**：為替リスクがない（輸入者との合意による）
3. **保険の併用**：為替変動保険との組み合わせ

### 円安・円高の局面別の対応
- **円安が進行している場合**：外貨建てのファクタリングを維持する（売却時の円換算額が増える）
- **円高が進行している場合**：速やかにファクタリングを利用する（円換算額の目減りを回避する）

## トラブル事例と回避策

### ケース1：海外の取引先の倒産
売掛金が回収不能となった場合、ノンリコース契約であれば、ファクタリング会社が損失を負担します。

### ケース2：為替の急変動
手数料を上回る為替差損が生じた場合に備え、為替予約を併用して回避します。

### ケース3：商品のクレーム
取引先が「品質不良」を理由に支払いを拒否する場合に備え、商品検査について事前に合意しておくことが重要です。

### ケース4：輸出規制違反
制裁対象国向けの取引は差し止められるため、事前のコンプライアンスチェックが必須です。

## 中小企業の国際ファクタリングの活用方法

### 1. 小口の輸出から始める
最初は小口の取引で経験を積んでください。

### 2. 銀行系を優先して選ぶ
信頼性・サポート体制が充実しています。

### 3. JETRO等の支援の活用
日本貿易振興機構が無料で相談に応じています。

### 4. 商工会議所の貿易部門の活用
地域の商工会議所が情報を提供しています。

### 5. 専門家との連携
通関士・行政書士・海外取引を専門とする弁護士と連携してください。

---

## まとめ

- 国際ファクタリングは、輸出取引の与信リスクの回避と早期の資金化に有効
- 2当事者制（Export Factor + Import Factor）が主流
- 手数料は1〜10%（国内より安い場合もある）
- 銀行系・国際的なFCIネットワーク経由の利用が安全
- L/Cとの併用も可能

グローバルに事業を展開する企業にとって、国際ファクタリングは有効な財務手段の一つです。

## よくある質問(FAQ)

**Q: 中小企業でも国際ファクタリングを利用できますか？**
A: 利用できますが、取引額・実績によります。年間の輸出額1億円以上が一般的な目安です。

**Q: 個人事業主のフリーランスにも対応していますか？**
A: 多くの国際ファクタリング会社は、法人のみに対応しています。個人事業主の方は、[国内のファクタリング](/articles/article-factoring-kojin-jigyonushi/)から始めることをおすすめします。

**Q: 国際ファクタリングは違法ではありませんか？**
A: 合法です。世界で標準的な金融取引として、50年以上の歴史があります。

**Q: 円建てと外貨建ては、どちらが有利ですか？**
A: 円高の局面では円建て、円安の局面では外貨建てが有利です。為替の見通しによって判断してください。

**Q: 国際ファクタリングと輸出保険の違いは？**
A: 輸出保険は損害の填補のみですが、国際ファクタリングは資金化と保証の両方を提供します。両者は併用できます。
