# 小売業のファクタリング｜対象になる売上・ならない売上と官公庁への納品の支払期限

**メタdescription:** 小売業で申し込めるのは法人や官公庁への掛売りの請求書で、店頭の個人客の売上は対象外とする会社が多くあります。政府契約の支払遅延防止法の期限と、売掛先の条件を公式に書いている会社の表示をまとめました（2026年11月確認）。
**対策KW:** 小売業 ファクタリング, 小売 資金繰り, 小売店 資金調達
**月間検索Vol:** 300〜500
**想定文字数:** 5,500字
**ステータス:** 下書き

---

小売業でファクタリングに申し込めるのは、法人や官公庁・学校などへ掛けで売った代金の請求書です。店頭で個人のお客様に売った代金は、その場で支払われるか決済サービスから入金されるもので、当サイトの掲載社の公式の記載でも、個人向けの債権やカード売上を対象外と明記している会社があります。

この記事では、売上の形ごとに申込みの対象になるかを掲載社の公式の記載で整理し、官公庁や公立学校に納品した場合の支払期限を法律の条文で確かめます。

## 売上の形ごとの扱い（掲載社の公式の記載）

| 売上の形 | 支払ってくる相手 | 掲載社の公式の記載の例 |
|---|---|---|
| 店頭の個人客への販売（現金・カード・QR） | 個人客、決済サービス | インボイスPayは対象外の債権に「カード売上」を挙げています（2026年10月31日確認）。当サイトの掲載59社のデータには、カード売上や決済サービスからの入金を買取の対象とする記載を記録した会社はありません |
| 個人客への後払い・掛売り | 個人 | GMO BtoB早払いは「個人向け債権」を対象外、MF早期入金は個人・個人事業主向け債権を不可と記載（いずれも2026年10月31日確認） |
| 法人への卸売り・掛売り（飲食店・ホテル・企業への納品など） | 法人 | 各社の売掛先の条件の範囲で申込みの対象 |
| 個人事業主の店への卸売り | 個人事業主 | ビートレーディングは「売掛先が個人事業主の売掛金」を対象外（2026年10月31日確認）。ペイトナーは個人の取引先も可（2026年11月1日確認） |
| 官公庁・自治体・公立学校への納品 | 国・地方公共団体 | OLTAは売掛先を「国内登記の法人または公的機関」、MF早期入金は「自治体・官公庁向け債権は対象」と記載（いずれも2026年10月31日確認） |

ショッピングセンターなどに出店していて施設から売上が精算される場合は、売掛先が施設の運営会社になります。精算日や、精算金を他社に譲渡できるかは出店契約に書かれているため、契約書を確かめてから申込先に相談してください。ECモールの売上の扱いは[EC・通販事業者のファクタリング](/articles/article-factoring-ec/)で整理しています。

## 官公庁・学校への納品は法律で支払期限が決まっている

### 政府契約の支払遅延防止等に関する法律

国と結ぶ契約の支払時期は「政府契約の支払遅延防止等に関する法律」で決まっており、同法第14条により地方公共団体の契約にも準用されます（[e-Gov法令検索](https://laws.e-gov.go.jp/law/324AC1000000256)・2026年11月16日確認）。物品の納入など工事以外の契約にかかる部分は次のとおりです。

| 条文 | 書かれていること |
|---|---|
| 第4条 | 契約の締結に際し、給付の完了の確認又は検査の時期、対価の支払の時期、遅延利息などを書面（電磁的記録を含む）で明らかにする |
| 第5条第1項 | 検査の時期は、相手方から給付を終了した旨の通知を受けた日から、工事は14日、その他の給付は10日以内の日とする |
| 第6条第1項 | 支払の時期は、検査を終了した後、適法な支払請求を受けた日から、工事代金は40日、その他の給付の対価は30日以内の日とする |
| 第7条 | 契約の性質上これによりがたい特殊な内容のものは、合意で特別の期間を定められるが、最長期間に1.5を乗じた日数以内とする |
| 第8条第1項 | 約定の支払時期までに支払わない場合、財務大臣が銀行の一般貸付利率を勘案して決定する率で計算した遅延利息を下回ってはならない |
| 第14条 | この法律（第12条及び第13条第2項を除く）は、地方公共団体のなす契約に準用する |

例：市立小学校に備品を納品した場合（仮定）

```
11月4日   納品を終えたことを市に通知
11月14日  この日までに検査（第5条：その他の給付は10日以内）
11月14日  検査終了の日に適法な請求書を提出したと仮定
12月14日  この日までに支払（第6条：請求から30日以内）
```

この仮定では、納品の通知から入金まで最長でおよそ40日です。年度末の納品が多い場合でも、検査と請求が済めば期限が決まるため、ファクタリングを使うかどうかは「期限まで待てるか」で判断できます。請求の内容の不当が軽微な過失による場合、国が請求を拒否した日から改めた請求を受けた日までの期間は約定期間に算入しないとされています（第6条第2項）。

期日の条件を持つ会社に申し込む場合は、この期限と組み合わせて考えます。例えば、OLTAは「入金期日が申込日から6営業日以上かつ6ヶ月以内の債権」を対象としています（2026年10月31日確認）。上の例で12月14日が入金期日なら、その6営業日前より後の申込みは条件に当てはまらなくなります（仮定の例。実際の可否は申込先で確かめてください）。急ぐ場合は、検査が終わり請求書を出した時点で申し込むかどうかを決める必要があります。

公的機関宛ての請求書で申し込む場合は、売掛先に公的機関を含むと公式に書いている会社（OLTA・MF早期入金）を候補にできます。ただし、自治体との契約に債権の譲渡を制限する条項がないかは、契約書で確かめてください。

### 大手の販売品を製造・修理して納める場合は取適法

自店で菓子・パン・雑貨などを作っている小売店が、大手の小売店や卸の販売品を製造して納める場合や、大手が請け負った物品の修理を受託する場合は、「製造委託等に係る中小受託事業者に対する代金の支払の遅延等の防止に関する法律」（取適法）の対象になることがあります（[e-Gov法令検索](https://laws.e-gov.go.jp/law/331AC0000000120)・2026年11月16日確認）。

| 条文 | 書かれていること |
|---|---|
| 第2条第1項 | 「製造委託」には、事業者が業として行う販売の目的物たる物品の製造を他の事業者に委託することが含まれる |
| 第2条第2項 | 「修理委託」には、事業者が業として請け負う物品の修理の行為の全部又は一部を他の事業者に委託することが含まれる |
| 第2条第8項・第9項 | 製造委託・修理委託では、資本金3億円超の法人から個人または資本金3億円以下の法人への委託、資本金1,000万円超3億円以下の法人から個人または資本金1,000万円以下の法人への委託、常時使用する従業員300人超の法人から300人以下の事業者への委託などが対象 |
| 第3条第1項 | 支払期日は、給付を受領した日から起算して60日の期間内で、かつ、できる限り短い期間内で定める |
| 第4条第1項 | 委託事業者は、給付の内容・代金の額・支払期日・支払方法などを、直ちに書面又は電磁的方法で明示する |
| 第5条第1項第2号 | 支払期日の経過後なお支払わないことを禁止。手形の交付や、支払期日までに金銭と引き換えることが困難な支払手段の使用も含む |

この法律にあたる取引なら、納品から60日以内に代金が支払われる仕組みです。ファクタリングを検討する前に、相手から明示された支払期日（第4条）がこの範囲に入っているかを確かめてください。取適法とファクタリングの関係は[ファクタリングと取適法（旧下請法）](/articles/article-factoring-shitaukehou/)で説明しています。

## 売掛先の条件を公式に書いている会社（手数料の下限が低い順）

小売業の請求書で問題になりやすいのは、売掛先が法人か、個人事業主か、公的機関かという点です。当サイトの掲載社のうち、売掛先の範囲を公式に具体的に書いている会社から7社を、**手数料の下限の表示が低い順**に並べました。優劣を示すものではありません。

| 会社 | 手数料の公式表示 | 売掛先についての公式の記載 | 対象（利用者） | 確認日 |
|---|---|---|---|---|
| [MF早期入金](/companies/mf-earlypayment/) | 0.5%〜（上限の記載なし） | 国内法人に限る（自治体・官公庁向けは対象、個人・個人事業主向けは不可）。役務提供完了済みの債権のみ | 法人のみ | 2026年10月31日 |
| [GMO BtoB早払い](/companies/gmo-btob-hayabarai/) | 請求書買取1%〜10% | 法人間取引に基づく売掛債権。個人向け債権・補助金・助成金は対象外。1回あたり合計100万円以上 | 法人のみ | 2026年10月31日 |
| [OLTA](/companies/olta/) | 2〜9%（諸経費込み） | 国内登記の法人または公的機関のみ。入金期日が申込日から6営業日以上かつ6ヶ月以内 | 法人・個人事業主 | 2026年10月31日 |
| [インボイスPay](/companies/invoice-pay/) | 2.5%〜6%（実勢手数料。最大10%） | 対象外の債権に、売掛先が個人事業主・飲食店・カード売上・20万円未満などを記載 | 法人のみ（個人事業主は取扱停止中） | 2026年10月31日 |
| [ビートレーディング](/companies/be-trading/) | 2社間4%〜（自社コラム内の表記） | 売掛先が法人であれば創業時期を問わない。売掛先が個人事業主の売掛金は対象外 | 法人・個人事業主・フリーランス | 2026年10月31日 |
| [バイオン](/companies/bion/) | 一律10%（別途振込手数料500円） | 売掛先が個人でも申請可（国内のみ） | 法人・個人事業主・フリーランス | 2026年10月31日 |
| [ペイトナー](/companies/paytner/) | 一律10%（別途振込手数料330円） | 個人の取引先も可。支払期日まで70日以内の請求書 | 個人事業主・一人法人（法人も可） | 2026年11月1日・11月2日・11月5日 |

出典：当サイトの[手数料・入金スピードの一覧](/fees/)と各社ページの検証欄（各社の公式サイトで確認）

例えば、個人経営の飲食店や美容室に商品を卸している場合、売掛先は個人事業主です。ビートレーディングやインボイスPayでは対象外で、バイオンやペイトナーは対象になりうる、というように会社選びが変わります。売掛先が個人の請求書の扱いは[売掛先が個人の請求書はファクタリングできる？](/articles/article-factoring-urikakesaki-kojin/)でも整理しています。

## 計算例（仮定）

```
仮定：
・ホテルへの客室備品の納品の請求書：200万円
・手数料率：4%（仮定。実際の率は申込先の見積もりで確認）

計算：
・手数料：200万円 × 4% ＝ 8万円
・受取額：200万円 − 8万円 ＝ 192万円
```

仕入れの前に資金が必要で、手元に請求書がない場合、在庫そのものを資金化する方法はファクタリングとは別の仕組みです。[在庫ファクタリングとは](/articles/article-zaiko-factoring/)で違いを説明しています。

## 申込み前に確かめること

1. **売掛先の種類**：法人・個人事業主・公的機関のどれか。会社によって対象が分かれます
2. **支払期日**：OLTAは6営業日以上6ヶ月以内、ペイトナーは70日以内など、期日の条件を確かめます
3. **契約書の譲渡制限**：自治体との契約や出店契約に、代金の債権を他社に譲渡することを制限する条項がないか確かめます
4. **金額の下限**：インボイスPayは20万円未満が対象外、GMO BtoB早払いは1回あたり合計100万円以上です

## よくある質問

**Q: 店頭のクレジットカード売上をファクタリングできますか？**

A: 当サイトの掲載59社のデータには、カード売上を買取の対象とする記載を記録した会社はなく、インボイスPayは対象外の債権に「カード売上」を挙げています（2026年10月31日確認）。カード会社や決済サービスからの入金日は、加盟店契約や管理画面でご確認ください。

**Q: 市役所や公立学校への納品の請求書は使えますか？**

A: OLTAは売掛先に「公的機関」を含め、MF早期入金は「自治体・官公庁向け債権は対象」と公式に書いています（いずれも2026年10月31日確認）。なお、地方公共団体の契約は、検査が通知から10日以内、支払が請求から30日以内と法律で決まっているため（政府契約の支払遅延防止等に関する法律第5条・第6条・第14条）、待てる期間かどうかもあわせて考えてください。

**Q: 個人経営のお店に卸した代金の請求書は使えますか？**

A: 売掛先が個人事業主になるため、会社によって扱いが分かれます。ビートレーディング・インボイスPay・MF早期入金は対象外、バイオン・ペイトナーは個人の取引先でも申請できると公式に書いています。

**Q: 仕入れの前に資金を用意したいのですが、請求書がまだありません。**

A: ファクタリングは発生済みの請求書（売掛金）が前提です。請求書がない段階の資金は、融資や制度融資を検討してください。[制度融資とは](/articles/article-seido-yuushi/)で自治体の制度を説明しています。
