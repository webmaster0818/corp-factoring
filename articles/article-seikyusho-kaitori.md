## 請求書買取（ファクタリング）とは？

### 具体的な仕組み（図解的な説明）

請求書買取サービス（ファクタリング）とは、**企業や個人事業主が取引先に発行した請求書（売掛債権）を、ファクタリング会社に売却して早期に現金化するサービス**です。

通常の取引では「請求書発行→30日〜90日後に入金」というフローが一般的ですが、その待ち時間を解消できます。

**具体的な流れ（例：100万円の請求書）**

```
4月1日  ：A社（取引先）に100万円の請求書を発行
          └→ 本来の入金予定は5月31日（60日後）

4月1日  ：請求書買取サービスに申込・審査（最短10分〜）

4月1日  ：手数料10%（10万円）を差し引いた90万円が即日振込

5月31日 ：A社からの100万円をファクタリング会社が直接回収
```

**ポイントは3つ**

1. **あなたは現金を手に入れる**（手数料分は差し引かれる）
2. **返済は不要**（売掛金の回収義務はファクタリング会社に移る）
3. **取引先への通知は原則不要**（2社間ファクタリングの場合）

### 借入との5つの違い（詳細比較表）

請求書買取は「借入ではなく売買」という性質から、銀行融資やビジネスローンとは根本的に異なります。

| 比較項目 | 請求書買取（ファクタリング） | 銀行融資・ビジネスローン |
|---------|--------------------------|----------------------|
| **法的性質** | 債権の売買（売却） | 金銭の貸借（借入） |
| **信用情報への影響** | **なし**（ブラックでも利用可） | あり（返済遅延で傷つく） |
| **審査の基準** | 売掛先（取引先）の信用力 | 申込者自身の信用力・財務状況 |
| **返済義務** | **なし**（ノンリコースの場合） | あり（毎月元本＋利息） |
| **調達スピード** | **最短10分〜即日** | 数日〜数週間 |
| **利用可能条件** | 有効な売掛金があれば可 | 黒字経営・担保・保証人等が必要な場合あり |
| **赤字・税金滞納** | **利用できるケース多い** | ほぼ不可 |
| **コスト** | 手数料（1%〜20%程度） | 金利（年率数%〜十数%） |

**最大のメリット：「借金ではない」こと**

ファクタリングは信用情報機関（CICやJICCなど）に記録されません。将来の住宅ローンや事業融資にまったく影響しないため、「今の資金繰りを解決しつつ、将来の借入枠を守る」という賢い使い方ができます。

### 2社間と3社間ファクタリングの違い

請求書買取には大きく分けて2つの方式があります。

**2社間ファクタリング**

```
あなた ←→ ファクタリング会社
（取引先には通知しない）
```

| 特徴 | 内容 |
|------|------|
| 取引先への通知 | **不要**（バレない） |
| 手数料 | やや高め（4%〜20%程度） |
| 入金スピード | **最速**（最短10分） |
| 売掛金回収 | あなたが取引先から回収してファクタリング会社に渡す |
| おすすめ | 取引先に知られたくない方・急ぎの方 |

**3社間ファクタリング**

```
あなた ←→ ファクタリング会社
       ↑
   取引先（通知・承諾が必要）
```

| 特徴 | 内容 |
|------|------|
| 取引先への通知 | **必要**（承諾が必要） |
| 手数料 | 安い（1%〜9%程度） |
| 入金スピード | やや遅い（数日〜1週間） |
| 売掛金回収 | ファクタリング会社が直接回収 |
| おすすめ | 手数料を抑えたい・取引先との関係が良好な方 |

**結論：初めての方は2社間がおすすめ**。取引先に知られずスピーディーに現金化できます。手数料を最優先するなら3社間を検討しましょう。

## 請求書買取サービスの選び方7つのポイント

多くのサービスの中から適切なものを選ぶための基準を詳しく解説します。

### 1. 手数料の「上限」を必ず確認する

広告で「1%〜」と表示されていても、実際に適用される手数料が10%や20%になるケースがあります。重要なのは**「下限」ではなく「上限」**の確認です。

**確認すべき項目**
- 手数料の上限（例：〜9.5%、〜10%、〜20%）
- 事務手数料・印紙代・その他諸費用の有無
- 早期解約時の違約金や追加費用

手数料が明示されているサービス（PAYTODAY：1〜9.5%、OLTA：2〜9%、日本中小企業金融サポート機構：1.5〜10%）は特に安心です。

詳細は[ファクタリング手数料の相場と安い会社12選](/articles/article-factoring-tesuryo/)もご参照ください。

### 2. 入金スピードを確認する

「最短即日」の表現は多くのサービスが使いますが、実際の入金タイミングは大きく異なります。

**確認ポイント**
- 申込から入金までの実際の所要時間
- 何時までに申込すれば当日入金か（締め切り時間）
- 土日祝の対応可否
- 繁忙期（月末など）の遅延リスク

緊急性が高い場合は、「最短10分」のペイトナーや「最短30分」のラボル・PAYTODAYを選びましょう。

### 3. 必要書類の少なさ

書類が多いほど申込の手間と時間がかかります。緊急時には特に重要です。

**書類数の比較**
- 最少クラス（2点）：QuQuMo、ビートレーディング（請求書＋通帳）
- 標準（3点）：アクセルファクター、ベストファクター（上記＋身分証）
- 多め（5点以上）：一部の銀行系・大手系

freeeやマネーフォワードとの連携サービス（OLTA等）は、会計ソフトから自動取り込みできるため書類準備が最も楽です。

### 4. オンライン完結か確認する

来店・郵送・対面が不要なオンライン完結型サービスは、地方在住者や時間が取れない方に必須です。

**オンライン完結の確認ポイント**
- 申込・審査・契約・入金がすべてオンラインで完結するか
- 電子契約（電子署名）に対応しているか
- スマホだけで操作できるか

今回紹介した20社のほぼすべてがオンライン完結に対応しています。ただし一部サービスは大口案件では対面での追加確認を求める場合があります。

### 5. 審査通過率を確認する

同じ請求書でも、サービスによって審査の通りやすさは大きく異なります。

**高通過率サービス**
- アクセルファクター：93%以上
- ベストファクター：92.2%
- 日本中小企業金融サポート機構：非営利で柔軟

**審査が通りにくいケースでも試すべき理由**
- 売掛先（取引先）の信用力が高ければ、申込者が赤字・税滞納でも通過するケースがある
- 複数社に同時申込することで、どこかが承認してくれる可能性が高まる

[ファクタリング審査に落ちた理由と対策](/articles/article-factoring-shinsa-ochita/)も参考にしてください。

### 6. 償還請求権（リコース）の有無を確認する

**これが最も重要な確認項目のひとつです。**

- **ノンリコース（償還請求権なし）**：取引先が倒産しても、あなたへの追加請求はない。**これが正しいファクタリング**。
- **リコース（償還請求権あり）**：取引先が支払わなかった場合、あなたが差額を補填しなければならない。これは実質的に「担保付き融資」に近い。

**必ずノンリコース（償還請求権なし）のサービスを選んでください。**

悪質な業者はリコース条件を後出しすることがあります。契約書を必ず確認しましょう。[悪質業者の見分け方と合法・違法の境界線](/articles/article-factoring-ihou/)もご確認ください。

### 7. 実績・口コミを確認する

利用者が多く、実績が豊富なサービスほど安心して利用できます。

**確認すべき指標**
- 累計利用社数・累計買取額
- 設立年数（長いほど信頼性高い）
- Googleの口コミ・第三者レビューサイトの評価
- 運営会社の情報（住所・電話番号・法人番号）

ビートレーディング（累計91,000社）やビジネスローン大手系のサービスは実績面で特に安心です。

## 請求書買取を利用する流れ（5ステップ）

初めての方向けに、申込から入金までの具体的なプロセスを解説します。

### STEP 1：サービスを選んで公式サイトで無料相談・申込（5〜10分）

公式サイトの申込フォームに必要事項を入力します。ほとんどのサービスは無料見積もりに対応しており、申込の前に「いくら受け取れるか」を確認できます。

**入力する主な情報**
- 会社名・屋号
- 請求書の金額・入金予定日
- 取引先の情報（会社名など）
- 希望入金日・急ぎ度

### STEP 2：必要書類をアップロード（5〜15分）

審査に必要な書類をオンラインでアップロードします。スマホで撮影したPDFや画像でOKです。

**一般的に必要な書類（サービスにより異なる）**
- 請求書（PDF・画像）
- 通帳のコピー（直近3ヶ月分の入出金が確認できるもの）
- 本人確認書類（身分証明書）※一部サービス不要
- 登記簿謄本・決算書（法人の場合、一部サービス）

### STEP 3：審査（最短10分〜数時間）

ファクタリング会社が請求書の内容と取引先の信用力を審査します。

**審査で確認されるポイント**
- 請求書の真正性（架空請求書でないか）
- 取引先（売掛先）の信用力・支払能力
- 取引の実態（反社・架空取引でないか）
- 申込者の基本情報

AI審査を採用しているサービス（PAYTODAY等）は最短10〜30分で完了します。

### STEP 4：審査通過・条件確認・電子契約（5〜10分）

審査通過後、以下の内容を必ず確認してから電子署名を行います。

**必ず確認すべき項目**
- 手数料率と実際に受け取る金額
- **償還請求権の有無（ノンリコースであるか）**
- 取引先への通知の要否
- 売掛金回収後の送金方法・期限
- 違約金・追加費用の有無

電子契約はPCまたはスマホで完結。印鑑・郵送は不要です。

### STEP 5：入金（最短10分〜）

電子契約完了後、指定口座に振込されます。

**入金タイミングの目安**
- ペイトナー：最短10分
- ラボル・PAYTODAY：最短30分
- QuQuMo・ビートレーディング：最短2時間
- その他多数：当日中〜翌営業日

**その後の流れ（2社間の場合）**
取引先からの入金（元の入金期日）を受け取ったら、速やかにファクタリング会社に送金します。送金期限を守ることが重要です。

## 利用時の注意点5つ

請求書買取サービスを安全・適切に利用するために知っておくべきポイントです。

### 1. 手数料の「上限」と「隠れコスト」を確認する

「1%〜」の低い下限だけでなく、実際に適用される上限と追加費用を必ず確認してください。

**チェックリスト**
- [ ] 手数料の上限は何%か
- [ ] 事務手数料・書類作成費用はかかるか
- [ ] 印紙代は誰が負担するか
- [ ] 振込手数料は差し引かれるか
- [ ] 解約・キャンセル時の費用はあるか

[ファクタリング手数料の相場と安い会社12選](/articles/article-factoring-tesuryo/)で相場感を把握しておきましょう。

### 2. 二重譲渡は絶対にしてはいけない

同じ請求書（売掛債権）を複数のファクタリング会社に売ることを「二重譲渡」といいます。これは**詐欺罪・横領罪に問われる可能性がある違法行為**です。

**絶対にしてはいけないこと**
- 同じ請求書を2社以上に申込む
- 既に別のサービスで買い取られた請求書を再度申込む
- 意図せず二重譲渡にならないよう、申込状況を正確に管理する

一度売却した売掛金は自分のものではありません。取引先から入金があっても、それはファクタリング会社のものです。

### 3. 悪質業者・闇金の見分け方

ファクタリングを装った闇金業者も存在します。以下の特徴がある業者は絶対に避けてください。

**警戒すべき特徴**
- 手数料が30%を超える（10%超でも要注意）
- 「審査なし・必ず通る」と謳っている（まともな審査なしでは安全性に問題）
- 契約書を渡さない・電子署名を求めない
- 会社の住所・電話番号・法人番号が不明確
- 執拗な電話・訪問営業をしてくる
- 買取額の一部を現金で手渡しすると言ってくる
- 取引先への直接連絡を禁止する特別な条件がある

詳しくは[悪質ファクタリング業者の見分け方と対処法](/articles/article-factoring-ihou/)をご確認ください。

### 4. 経理処理・確定申告の扱い

ファクタリングは「売却」であるため、経理処理は融資とは異なります。

**勘定科目の処理**

```
【売掛金を売却した時】
（借方）普通預金  900,000    （貸方）売掛金  1,000,000
（借方）売上債権売却損  100,000

手数料10万円は「売上債権売却損」で費用計上
```

**確定申告への影響**
- 手数料（売上債権売却損）は**経費として計上できる**
- 消費税は**非課税**（金融取引のため）
- 売上自体は変わらない（売掛金を早期回収しただけ）

詳細は[ファクタリングの仕訳・勘定科目の処理方法](/articles/article-factoring-shiwake/)と[ファクタリングと確定申告（個人事業主向け）](/articles/article-factoring-kojin-kakutei/)をご参照ください。

### 5. 継続利用によるコスト増大リスク

資金繰りが改善しないままファクタリングを繰り返し利用すると、**手数料が積み重なってキャッシュフローがさらに悪化**するリスクがあります。

**継続利用の適切な使い方**
- 一時的な資金不足の解消（季節変動・突発的支出）に活用
- 銀行融資が通るまでのつなぎとして活用
- 新規取引先との信頼関係が確立するまでのリスクヘッジとして活用

**注意すべきサイン**
- 毎月ファクタリングなしでは資金が回らない状態
- 手数料コストが月商の5%を超えている
- 利用額がじわじわと増えている

継続利用のリスクと対策については[ファクタリングの継続利用リスクと改善策](/articles/article-factoring-keizoku-riyou/)もご参照ください。

## 請求書買取と他の資金調達方法を比較

請求書買取だけが資金調達の選択肢ではありません。状況に応じた最適な方法を選びましょう。

### 3者比較表

| 比較項目 | 請求書買取（ファクタリング） | 銀行融資 | ビジネスローン |
|---------|--------------------------|---------|--------------|
| **調達スピード** | **最短10分〜即日** | 数週間〜2ヶ月 | 最短即日〜数日 |
| **審査難易度** | **易しい**（売掛先基準） | 厳しい | 中程度 |
| **赤字・税滞納** | **対応可能なケース多い** | ほぼ不可 | 一部可能 |
| **信用情報への影響** | **なし** | あり | あり |
| **返済義務** | **なし** | あり | あり |
| **コスト** | 手数料1%〜20% | 金利1%〜5% | 金利5%〜18% |
| **担保・保証人** | **不要** | 必要な場合多い | 不要なことが多い |
| **調達上限** | 売掛金の範囲内 | 数千万円〜億単位 | 数十万〜数千万円 |
| **繰り返し利用** | 毎回新規申込が必要 | 不要（枠内） | 不要（枠内） |

### どれを選ぶべきか？

**請求書買取（ファクタリング）が最適な場合**
- 今すぐ（今日中に）資金が必要
- 銀行融資の審査が通らない（赤字・創業間もない等）
- 信用情報を傷つけたくない
- 担保や保証人を用意できない
- 返済負担を増やしたくない

**銀行融資が最適な場合**
- まとまった資金を長期で調達したい
- 黒字経営で財務状況が良好
- 金利コストを最小化したい
- 設備投資・事業拡大など明確な使途がある

**ビジネスローンが最適な場合**
- 売掛金がない（小売業・飲食業等）
- 銀行融資は厳しいが、ある程度の信用情報がある
- 中程度の金額（数十万〜数百万円）が必要

[ファクタリングと銀行融資の徹底比較](/articles/article-factoring-vs-ginkou/)と[ファクタリングとビジネスローンの違いを解説](/articles/article-factoring-vs-yuushi/)も合わせてご覧ください。

## 業種別おすすめ請求書買取サービス

業種によって利用のしやすさや特化サービスが異なります。

**おすすめ：PAYTODAY、FREENANCE、ペイトナーファクタリング**

IT業界は請求書払いが一般的で、案件単位の支払いサイト（30〜60日）も多く、ファクタリングとの相性が抜群です。

| ポイント | 内容 |
|---------|------|
| 特徴 | フリーランス・小規模開発会社が多い |
| 手数料の優先度 | 高い（少額案件が多いため費用対効果を意識） |
| スピードの優先度 | 高い（プロジェクト完了後の資金繰りに） |
| おすすめ | PAYTODAY（スピード×低手数料）、FREENANCE（GMO×保険） |

詳しくは[IT・システム開発向けファクタリングおすすめ](/articles/article-factoring-it/)をご参照ください。

### 建設・工事・リフォーム

**おすすめ：ビートレーディング、アクセルファクター、経営財務研究所**

建設業は工期が長く、元請けへの請求から入金まで2〜3ヶ月かかることも多いため、ファクタリングのニーズが特に高い業種です。

| ポイント | 内容 |
|---------|------|
| 特徴 | 大口案件が多く、資金繰り問題が深刻 |
| 手数料の優先度 | 非常に高い（大口ほどコスト差が大きい） |
| スピードの優先度 | 中（仕入れ・外注費の支払いに合わせて） |
| おすすめ | QuQuMo（最安手数料×大口対応）、ビートレーディング（実績・信頼性） |

詳しくは[建設業向けファクタリングおすすめ10選](/articles/article-factoring-kensetsu/)をご参照ください。

### 医療・介護・福祉

**おすすめ：医療ファクタリング専門社、ビートレーディング**

医療機関は診療報酬の入金が通常2ヶ月後（審査支払機関経由）のため、開業直後や経営安定前のつなぎ資金として有効です。

| ポイント | 内容 |
|---------|------|
| 特徴 | 診療報酬債権の買取が中心 |
| 手数料の優先度 | 高い（低手数料特化サービスがある） |
| スピードの優先度 | 中（月次の入金タイミングに合わせて） |
| おすすめ | 医療ファクタリング専門社（1%〜5%の専門低手数料） |

詳しくは[医療・クリニック向けファクタリング完全ガイド](/articles/article-factoring-iryou/)をご参照ください。

### 飲食業・小売業

**おすすめ：ビートレーディング、アクセルファクター（掛け売りがある場合）**

飲食業・小売業は現金取引が多いためファクタリングの対象になる請求書が少ない場合がありますが、食材仕入れの掛け売りや法人向け仕出し・ケータリング事業では有効です。

| ポイント | 内容 |

## よくある質問（FAQ）10問

### Q1. 請求書1枚だけでも利用できますか？

**A. はい、できます。** ペイトナーファクタリング・ラボルは1万円の請求書1枚から対応しています。QuQuMoやビートレーディングも最低額の制限がなく、少額の請求書1枚でも申込可能です。

ただし、審査の結果によっては承認されないケースもあります。請求書が本物であり、取引先が実在する法人・個人事業主であることが条件です。

---

### Q2. 取引先（クライアント）にバレますか？

**A. 2社間ファクタリングなら原則バレません。** 今回紹介した20社の多くは2社間方式に対応しており、取引先への通知・承諾なしで利用できます。

ただし、以下のケースでは注意が必要です：
- 取引先の口座に「ファクタリング会社」からの問い合わせが届く可能性（まれ）
- 3社間ファクタリングを選んだ場合（必ず通知が行く）
- 取引先が複数回取引したことがあり、入金元が変わることに気づく場合

詳しくは[ファクタリングは取引先にバレる？2社間と3社間の違い](/articles/article-factoring-bareru/)をご覧ください。

---

### Q3. フリーランスでも利用できますか？

**A. はい、フリーランスでも問題なく利用できます。** ペイトナーファクタリング・ラボル・FREENANCE・ラボルはフリーランス特化型サービスです。

フリーランスが利用する場合のポイント：
- 個人事業主として開業届を出していなくても利用できるサービスもある
- 取引先が法人であれば審査通過率は高い
- 取引先が個人の場合、ペイトナーファクタリングが唯一の対応サービス

[個人事業主・フリーランス向けファクタリングおすすめ15選](/articles/article-factoring-kojin-jigyonushi/)も参考にしてください。

---

### Q4. 審査に落ちるのはどんなケースですか？

**A. 主に以下のケースで審査が通りにくいです：**

1. **請求書の取引先が個人（自然人）の場合**：多くのサービスは法人宛て請求書のみ対応（ペイトナー除く）
2. **請求書の信憑性に問題がある場合**：実態のない取引・架空請求書は即却下
3. **取引先の信用力が極めて低い場合**：倒産寸前の企業や、支払実績のない新規取引先など
4. **入金予定日が極端に遠い場合**：入金まで180日以上先など
5. **反社会的勢力との関係が疑われる場合**

赤字・税金滞納・創業間もない企業でも、取引先の信用力が高ければ審査通過できるケースが多いです。詳しくは[ファクタリング審査に落ちた原因と通過するための対策](/articles/article-factoring-shinsa-ochita/)をご覧ください。

---

### Q5. 手数料はどのくらいかかりますか？

**A. 一般的な相場は2%〜15%程度です（2社間）。**

| 条件 | 目安手数料 |
|------|-----------|
| 売掛先が大手企業・信用力高 | 2%〜5% |
| 売掛先が中小企業・一般的 | 5%〜12% |
| 売掛先の信用力が不明 | 10%〜20% |
| 少額（10万円以下） | 10%前後 |
| 大口（500万円以上） | 1%〜8% |

手数料を下げるコツは「複数社に見積もりを出す」「取引先の決算情報を提出して信用力を証明する」「継続利用で実績を積む」ことです。

詳しくは[ファクタリング手数料の相場と安くする方法](/articles/article-factoring-tesuryo/)をご参照ください。

---

### Q6. 即日入金は本当にできますか？

**A. はい、実際に即日（当日中）に入金されます。** ただし、以下の条件が必要です：

- 平日の午前中〜昼頃までに申込を完了する（サービスにより締め切り時間が異なる）
- 必要書類が揃っている
- 審査がスムーズに通過する

「最短10分」のペイトナーや「最短30分」のラボル・PAYTODAYは、特に午前中の申込であればほぼ当日中に入金されます。

[即日ファクタリングおすすめ15選と使い方](/articles/article-factoring-sokujitsu/)も参考にしてください。

---

### Q7. 確定申告にはどう影響しますか？

**A. 手数料分が経費になるだけで、売上自体は変わりません。**

- ファクタリング手数料は「売上債権売却損」として経費計上できる
- 消費税は非課税（金融取引のため）
- 年間の確定申告では、通常の売上・経費の計算に組み込まれる

例えば、100万円の請求書を手数料10%（10万円）で売却した場合：
- 売上：100万円（変わらない）
- 経費：10万円（売上債権売却損）
- 手取り：90万円

詳しくは[ファクタリングの確定申告・仕訳の方法（個人事業主向け）](/articles/article-factoring-kojin-kakutei/)をご確認ください。

---

### Q8. 赤字経営でも利用できますか？

**A. はい、利用できるケースがほとんどです。** ファクタリングの審査は申込者の財務状況ではなく、**売掛先（取引先）の信用力**を主に見るためです。

- アクセルファクター（審査通過率93%）・ベストファクター（92.2%）は特に赤字企業への対応実績が豊富
- ただし、赤字でも「継続的な取引実績がある」「売掛先が優良企業」であることが重要
- 複数社に申込することで、どこかが通過する可能性が高まる

[赤字でもファクタリングは使える？審査を通す方法](/articles/article-factoring-akaji/)もご参照ください。

---

### Q9. 複数の請求書をまとめて売却できますか？

**A. はい、可能です。** 多くのサービスは複数の請求書を一括で申込・買取できます。

ただし注意点として：
- 各請求書ごとに審査が行われる（まとめても審査は個別）
- 取引先が異なる複数請求書は同時に申込可能
- 同一取引先の複数請求書は一括申込できるサービスが多い

[複数の請求書を同時にファクタリングする方法](/articles/article-factoring-fukusu/)で詳しく解説しています。

---

### Q10. 起業・創業間もない会社でも利用できますか？

**A. はい、創業直後でも利用可能なケースが多いです。** 銀行融資と違い、事業歴よりも「有効な売掛金があるか」が重視されます。

- 創業1年未満でも、取引先が優良企業であれば審査通過の可能性が高い
- 決算書がなくても利用できるサービスが多い（ペイトナー・ラボル等）
- まずは少額から試して実績を積むのがおすすめ

[創業・起業間もない会社がファクタリングを使う方法](/articles/article-factoring-shigyou/)もご参照ください。

## まとめ

請求書買取（ファクタリング）は、売掛金を活用して資金繰りを改善する強力な手段です。2026年現在、多くの優れたサービスが登場し、最短10分・1万円から手軽に利用できる時代になりました。

| あなたの状況 | おすすめサービス | 理由 |
|------------|---------------|------|

| **土日・深夜に資金が必要** | ラボル | 24時間365日入金対応・唯一 |
| **コストを最小化したい** | QuQuMo | 手数料1%〜・業界最安水準 |
