## 売掛金とは何か？基礎から理解する

### 売掛金の定義

売掛金とは、**商品やサービスを提供したが、まだ代金を受け取っていない状態の債権（お金を受け取る権利）**のことです。

```
【売掛金が発生するフロー】
1. 商品・サービスを提供
2. 請求書を発行（支払期日：翌月末など）
3. 支払期日まで「売掛金」として計上
4. 入金完了 → 売掛金が消える
```

### 売掛金・未収金・売掛債権の違い

| 用語 | 意味 | 発生シーン |
|------|------|----------|
| **売掛金** | 営業活動で発生した未収の代金 | 本業の取引 |
| **未収金** | 営業外で発生した未収の代金 | 固定資産の売却など |
| **売掛債権** | 売掛金＋受取手形の総称 | 両方を含む |

ファクタリングで扱うのは主に「売掛金」と「受取手形」です。

## ファクタリングで現金化できる売掛金の条件

### 条件1：実在する取引から生じた売掛金であること

架空の売掛金や水増し請求書は利用できません。取引基本契約書・発注書・納品書などで裏付けができることが必要です。

### 条件2：支払期日が未到来であること

既に支払期日が過ぎた売掛金（過年度売掛金）は通常対象外です。[ファクタリングの審査基準](/articles/article-factoring-shinsa/)では支払期日も重要な判断材料となります。

### 条件3：二重譲渡されていないこと

同じ売掛金を複数のファクタリング会社に売ることは「二重譲渡」に当たり、詐欺罪になる可能性があります。[債権譲渡登記](/articles/article-factoring-saiken-touki/)でこれを防ぐ仕組みもあります。

### 条件4：売掛先が存在し、支払い能力があること

売掛先の倒産リスクが高い場合は審査が通りにくくなります。[売掛先が倒産した場合の対処法](/articles/article-factoring-urikakesaki-tousan/)についても確認しておきましょう。

## 売掛金の会計処理と仕訳

### 売掛金が発生したとき

```
（借方）売掛金 1,000,000円 ／ （貸方）売上高 1,000,000円
```

### ファクタリングで売却したとき

売掛金100万円を手数料5%（5万円）でファクタリングした場合：

```
（借方）現金・普通預金 950,000円
（借方）売上債権売却損   50,000円
       ／（貸方）売掛金 1,000,000円
```

詳しい仕訳方法は[ファクタリングの勘定科目・仕訳方法](/articles/article-factoring-kanjokamoku/)で解説しています。

## 売掛金の現金化スピードと手数料の関係

```
【手数料に影響する要因】
・売掛先の信用力（高いほど手数料が低い）
・支払期日までの日数（短いほど手数料が低い）
・売掛金の金額（大きいほど手数料が低い傾向）
・ファクタリングの種類（3社間＜2社間）
```

| パターン | 目安手数料 | 入金まで |
|---------|----------|--------|
| 大手上場企業の売掛金・3社間 | 1〜3% | 3〜7日 |
| 中堅企業の売掛金・2社間 | 5〜10% | 最短即日 |
| 中小企業の売掛金・2社間 | 10〜20% | 最短即日 |

## 売掛金管理のポイント

### 売掛金台帳の整備

ファクタリングを活用するためにも、**売掛金台帳（取引先別の管理表）**を常に最新状態に保つことが重要です。

```
売掛金台帳に記録すべき項目：
□ 取引先名
□ 請求日
□ 請求金額
□ 支払期日
□ 入金確認日・金額
□ 残高
```

### 売掛金回収サイクルの把握

**回収サイクル（日数）＝ 売掛金残高 ÷ 売上高 × 365日**

この数値が長いほど資金繰りが苦しくなる傾向にあります。[資金繰り改善](/articles/article-factoring-shikinguri/)の第一歩は、この数値を把握することです。

## よくある質問（FAQ）

**Q: 売掛金とは何ですか？簡単に説明してください。**
A: 商品やサービスを提供したが、まだ代金を受け取っていない「将来受け取れる権利（お金）」のことです。

**Q: 売掛金はどのくらいの期間で現金化できますか？**
A: ファクタリングを使えば最短即日で現金化できます。3社間なら3〜7日、2社間なら即日〜翌日が目安です。

**Q: 売掛金が10万円以下でも現金化できますか？**
A: 少額対応のファクタリング会社を選べば可能です。1〜10万円程度から対応している会社もあります。

**Q: 売掛先に内緒で売掛金を現金化できますか？**
A: 2社間ファクタリングであれば、売掛先への通知なしに現金化できます。

**Q: 売掛金を現金化すると決算書に影響しますか？**
A: 売掛金が減少し、現金が増えるため貸借対照表に影響しますが、借入のように負債が増えることはありません。
