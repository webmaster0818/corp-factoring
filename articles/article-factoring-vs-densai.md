**ステータス:** 下書き

---

でんさいとは何か、ファクタリングとどのように違うのかを解説します。電子記録債権（でんさい）は、ファクタリングと並んで注目される資金調達の手段です。それぞれの違いを理解し、自社に合った方法を選んでください。

---

## でんさい（電子記録債権）とは

### 基本概念

でんさいとは、**電子的に記録・管理される売掛債権（電子記録債権）**の愛称で、「でんさいネット」（全銀電子債権ネットワーク）が運営するシステムで取り扱われます。

```
【でんさいの特徴】
・紙の手形・受取手形の電子版
・でんさいネットのシステムで管理
・2013年にサービスを開始
・大手銀行・地方銀行が参加
```

### でんさいの仕組み

```
【でんさいの発生の流れ】
1. 支払企業が、でんさいネットに「電子記録債権の発生」を登録する
2. 受取企業に通知される
3. 受取企業が内容を確認・承諾する
4. 支払期日に、自動で口座に振り込まれる
```

## ファクタリングとでんさいの比較

| 観点 | ファクタリング | でんさい（でんさい割引） |
|-----|-------------|-----------------|
| **仕組み** | 売掛金を第三者に売却 | 電子記録債権を銀行に割り引いてもらう |
| **対象となる債権** | 一般的な売掛金 | でんさいとして登録された電子記録債権 |
| **利用する機関** | ファクタリング会社 | 銀行（でんさいネット参加行） |
| **コスト** | 手数料（率は会社・方式で異なる） | 割引料（市場金利＋αで1〜3%程度） |
| **スピード** | 最短即日 | 申込後、数日 |
| **審査** | 売掛先を重視 | 申込者の信用力も重視 |
| **返済義務** | なし（ノンリコース） | 遡及義務あり（でんさい割引の場合） |
| **取引先の承諾** | 2社間では不要 | でんさい発生時に承諾が必要 |

## でんさい割引の仕組み

でんさいを資金化する方法として、「でんさい割引」があります。

```
【でんさい割引の流れ】
受取企業がでんさいを保有
  ↓
取引銀行に割引を申し込む
  ↓
銀行が審査し、割引料を提示する
  ↓
割引後の金額を受け取る（支払期日前に現金化）
  ↓
支払期日に、支払企業から銀行へ入金される
```

**遡及義務（リコース）：**
でんさい割引には遡及義務があり、支払企業が倒産した場合に、受取企業が買い戻す義務があります。この点が、ノンリコースのファクタリングと大きく異なります。

## でんさいのメリット・デメリット

### でんさいのメリット

| メリット | 内容 |
|---------|-----|
| 費用が低い | 割引料が1〜3%程度と低い |
| 紛失・盗難のリスクがない | 電子化されているため |
| 分割譲渡が可能 | 1つのでんさいを分割して利用できる |
| 手形より管理が容易 | 印紙税が不要・物理的な保管が不要 |
| 銀行との連携 | 既存の取引銀行で利用できる |

### でんさいのデメリット

| デメリット | 内容 |
|----------|-----|
| 普及率の課題 | でんさいに対応していない企業がある |
| 銀行の審査が必要 | 信用力が低い企業は、審査が厳しい |
| 遡及義務 | 支払企業の倒産時に、買戻しのリスクがある |
| 手続きが煩雑 | でんさいの発生の登録・承諾が必要 |
| 対応銀行の制限 | 参加していない金融機関がある |

## ファクタリングとでんさいの使い分け

### ファクタリングを選ぶべき場面

- 売掛先がでんさいに対応していない
- 急ぎで当日中に現金が必要（最短即日）
- 売掛先の倒産リスクを回避したい（ノンリコース）
- 銀行の融資枠を使いたくない

### でんさいを選ぶべき場面

- 費用を最小限に抑えたい（1〜3%）
- すでにでんさいで取引している取引先がある
- 分割譲渡が必要
- 銀行との関係を強化したい

---

## でんさいとファクタリングの組み合わせ

取引先がでんさいを利用している場合でも、ファクタリング会社によっては、でんさいを対象としてファクタリングを行うことができます。

```
【でんさいのファクタリングへの活用】
でんさい（電子記録債権）を保有
  ↓
でんさいに対応したファクタリング会社に譲渡する
  ↓
手数料を支払って、即日で現金化する
（でんさい割引より手数料は高いが、即日に対応）
```

## 手形・でんさい・ファクタリングの全体比較

| 項目 | 約束手形 | でんさい | ファクタリング |
|-----|---------|--------|-------------|
| **電子化** | なし | あり | 一部あり |
| **印紙税** | 必要 | 不要 | [不要](/articles/article-factoring-inshizei/) |
| **割引の費用** | 低い | 低い | 比較的高い |
| **現金化スピード** | 数日 | 数日 | 最短即日 |
| **倒産リスク** | 遡及あり | 遡及あり | ノンリコース |
| **普及度** | 減少傾向 | 拡大中 | 拡大中 |

## 政府・金融庁の方針

政府方針をもとに、産業界・金融界は2027年3月末までの手形・小切手の利用廃止に向けた取組みを進めており、全国銀行協会は2026年度末（2027年3月末）までに電子交換所における手形・小切手の交換枚数をゼロにすることを目標としています（出典：[全国銀行協会](https://www.zenginkyo.or.jp/tegata-kogitte-haishi/)・2026年10月17日確認）。また、2026年1月1日施行の取適法（旧下請法）では、対象取引の代金を手形で支払うことが禁止されています（出典：[公正取引委員会](https://www.jftc.go.jp/toriteki/index.html)）。

## まとめ

でんさいとファクタリングは、いずれも売掛金を前倒しで現金化する手段ですが、費用・スピード・倒産リスクの扱いで大きな違いがあります。でんさいを利用できる状況では費用を抑えられ、緊急性や倒産リスクの回避を優先する場合は、ファクタリングが適しています。[資金繰り改善](/articles/article-factoring-shikinguri/)の全体の計画の中で、適切な組み合わせを検討してください。

## よくある質問（FAQ）

**Q: でんさいとファクタリングは、どちらが費用を抑えられますか？**
A: でんさい割引のほうが、費用（割引料1〜3%）は低いのが一般的です。ただし、でんさいに対応していない取引先には利用できません。

**Q: でんさいを利用している場合、ファクタリングは利用できませんか？**
A: でんさいに対応しているファクタリング会社もあります。ただし、でんさい割引より手数料が高くなることが多くあります。

**Q: 手形からでんさいに切り替えるのは難しいですか？**
A: でんさいネットに参加している取引銀行があれば、手続き自体は難しくありません。ただし、取引先もでんさいに対応している必要があります。

**Q: 紙の手形が廃止されると、どうなりますか？**
A: 紙の手形・小切手は、2027年3月末までの利用廃止に向けた取組みが進められています（全国銀行協会）。廃止後は、でんさい（電子記録債権）や振込への移行が中心となります。ファクタリングも、引き続き利用できます。

**Q: でんさいの遡及義務（買戻し義務）には、どのように対処すればよいですか？**
A: 取引先の信用力を定期的に確認し、リスクが高いと判断した場合は、でんさいをファクタリングで売却する（ノンリコース化する）ことも選択肢です。
