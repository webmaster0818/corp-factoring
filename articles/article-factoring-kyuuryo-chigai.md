# ファクタリングと給料ファクタリングの違い｜違法性・リスクを比較【2026年】

**対策KW:** ファクタリング 給料ファクタリング 違い, 給与ファクタリング 違法
**月間検索Vol:** 800〜1,500
**想定文字数:** 5,000字
**ステータス:** 下書き

---

給料ファクタリングは違法なのか、通常のファクタリングとどのように違うのかを解説します。名称は似ていますが、事業者向けのファクタリングと給料ファクタリングは、**根本的に異なる性質**を持っています。

---

## ビジネスファクタリングと給料ファクタリングの根本的な違い

### 比較表

| 項目 | ビジネスファクタリング | 給料ファクタリング |
|-----|-----------------|--------------|
| **対象となる債権** | 法人・個人事業主の売掛金 | 会社員の給与・賃金 |
| **利用者** | 事業者（法人・個人事業主） | 会社員・アルバイト |
| **法的性質** | 債権の売買（合法） | 実質的な貸付け（**違法**） |
| **貸金業法** | 対象外 | **対象（無登録は違法）** |
| **最高裁の判断** | 合法 | **違法（2022年判決）** |
| **金利相当の上限** | 法的上限なし（自由） | 利息制限法20%が上限 |
| **リスク** | 手数料の負担 | 違法業者・過剰な取立て |

---

## 給料ファクタリングとは何か

### 仕組み

給料ファクタリングとは、**まだ受け取っていない給与（賃金債権）を第三者に売る**という形式をとるサービスです。

```
【給料ファクタリングの例】
月給25万円の会社員
「20万円の給与債権」を15万円で業者に売却
→ 手数料25%相当（年利換算で非常に高い水準）
→ 月末に給与から業者が回収
```

### 違法とされる理由

最高裁判所は2022年2月、給料ファクタリングは**実質的に貸金業法が規制する貸付けにあたる**と判断しました。

**理由：**
1. 給与（賃金）は、使用者が労働者本人に直接支払う義務がある
2. 「売却」の形式をとっていても、実質的には給与を担保に借入をした状態と変わらない
3. 無登録での貸金業（貸金業法違反）と、出資法違反（上限金利の超過）にあたる

---

## 給料ファクタリングの具体的なリスク

### リスク1：過剰な手数料・金利

合法な上限金利は年20%（利息制限法）ですが、給料ファクタリングの手数料を年利に換算すると、**数百〜数千%**になるケースがあります。

```
【ケースの例】
20万円の給料債権を15万円で購入
手数料：5万円（25%）
期間：15日（給与日まで）

年利換算：25% ÷ 15日 × 365日 = 608%
→ 利息制限法の上限（20%）の30倍超
```

### リスク2：違法業者による取立て・脅迫

給料ファクタリングを行う業者の多くは無登録業者（ヤミ金）であり、法的な規制を無視した過酷な取立てを行うケースがあります。

### リスク3：職場に知られるリスク

業者が勤務先に電話をかけ、給与の確認や取立てを行うケースがあり、職場での地位や信用を失う可能性があります。

### リスク4：債務の悪循環

一時的な対応のために給料ファクタリングを利用した結果、次の給料日に手元に資金が残らず、再び利用するという悪循環に陥るケースが多く見られます。

## 給料ファクタリングを利用してしまった場合の対処法

### 対処法1：消費生活センターへの相談

国民生活センター（0570-064-370）や、各都道府県の消費生活センターに相談できます。

### 対処法2：弁護士・司法書士への相談

無料の法律相談を活用し、払いすぎた手数料（実質的な利息）の返還を請求できる場合があります。

### 対処法3：金融庁・警察への通報

無登録で貸金業を行っている業者は、金融庁や警察への通報の対象です。

## 給料ファクタリングに代わる合法な方法

| 方法 | 内容 | 注意点 |
|-----|-----|-------|
| 公的支援（生活福祉資金） | 都道府県社会福祉協議会による低利貸付け | 審査あり |
| 労働金庫のカードローン | 年利5〜14.5%程度 | 組合員向け |
| 銀行系カードローン | 年利5〜14.9%程度 | 信用情報の審査あり |
| 消費者金融 | 年利18〜20% | 上限金利の範囲内 |
| 勤務先への前払いの相談 | 給与の一部を前払い | 会社による |

## 事業者向けファクタリングとの混同を防ぐために

### 見分け方

| 項目 | 正規ファクタリング | 給料ファクタリング |
|-----|----------------|--------------|
| 対象者 | 法人・個人事業主 | 会社員・アルバイト |
| 対象の売掛金 | 事業の取引先への請求書 | 給与・賃金 |
| 「貸金業登録」 | 不要（売買契約） | 必要（実質貸付け） |

個人事業主の[売掛金のファクタリング](/articles/article-factoring-kojin-jigyonushi/)は合法ですが、個人の「給料」を対象とするサービスは、まったく異なるものです。

## まとめ

事業者向けファクタリング（事業の売掛金の売買）は合法ですが、給料ファクタリング（給与の前払いを装った貸付け）は、最高裁で違法と判断されています。「ファクタリング」という名称にとらわれず、対象の違いを必ず確認してください。

## よくある質問（FAQ）

**Q: 給料ファクタリングは違法ですか？**
A: 違法です。2022年の最高裁判決で、給料ファクタリングは貸金業法が規制する貸付けにあたると判断されており、無登録業者による実施は違法です。

**Q: 給料ファクタリングを利用すると、犯罪になりますか？**
A: 利用者が犯罪に問われるわけではなく、違法となるのは業者側です。払いすぎた手数料は、返還を請求できる可能性があります。

**Q: 事業者向けファクタリングと給料ファクタリングを見分けるポイントは？**
A: 何の債権を買い取るかが重要です。事業の請求書であれば合法、個人の給与であれば違法です。

**Q: 会社員が、事業収入（副業）の売掛金をファクタリングで資金化できますか？**
A: 事業収入の売掛金（請求書）であれば、合法的に利用できます。副業・フリーランスの収入の請求書は、事業者向けファクタリングの対象です。

**Q: 給料ファクタリングで困っている場合、どこに相談すればよいですか？**
A: 国民生活センター（0570-064-370）、弁護士・司法書士（法テラス0120-007-110で紹介を受けられます）にご相談ください。
