# 個人事業主がお金を借りる先の違い｜銀行・公庫・貸金業者と請求書の売却

**対策KW:** 個人事業主 お金借りる
**メタdescription:** 個人事業主の借入先は銀行・信用金庫、日本政策金融公庫、貸金業者、小規模企業共済の貸付に分かれ、総量規制や審査書類が違います。利息制限法の上限金利と、請求書を売る場合の手数料を公式情報とデータで比べました。
**想定文字数:** 6,000字
**ステータス:** 下書き

個人事業主がお金を借りる先は、銀行・信用金庫などの金融機関、日本政策金融公庫、ビジネスローンなどを扱う貸金業者、小規模企業共済の契約者貸付に分かれ、どこから借りるかで適用される規制と審査に出す書類が変わります。取引先への請求書（売掛金）がある場合は、借りる代わりに売掛金を売るファクタリングも、費用と条件を並べて比べる価値があります。

この記事では、借入先ごとの違いを貸金業法・利息制限法などの条文と、日本貸金業協会・日本政策金融公庫・中小機構の公式ページで確認した内容で整理し、そのうえで売掛金を売る場合との使い分けを、当サイトが各社公式で確認したデータで示します。

## 借入先の4つの区分と、それぞれのルール

| 区分 | 例 | 総量規制（年収の3分の1） | 公式に確認できる主な条件 |
|------|------|------|------|
| 銀行・信用金庫・信用組合 | 事業性の融資、カードローン | 対象外（貸金業者ではないため） | 各金融機関の基準による |
| 日本政策金融公庫 | 国民生活事業の事業資金 | ― | 確定申告書一式2期分などの提出（申告前の方は不要） |
| 貸金業者 | ビジネスローン、事業者金融、クレジットカードのキャッシング | 個人事業者への貸付けも原則対象。事業計画等で返済能力が認められれば例外あり | 返済能力の調査、信用情報の使用、一定額を超えると収入証明の提出 |
| 小規模企業共済の契約者貸付 | 一般貸付 | ― | 掛金を12か月以上納付、納付した掛金の範囲内、年1.5% |

（出典：日本貸金業協会「[お借入れは年収の3分の1まで](https://www.j-fsa.or.jp/association/money_lending/law/annual_income.php)」「[総量規制が適用されない場合について](https://www.j-fsa.or.jp/association/money_lending/law/total_regulation.php)」、[日本政策金融公庫 インターネット申込（事業資金）](https://www.jfc.go.jp/n/service/apply.html)、[小規模企業共済「契約者貸付の概要」](https://kyosai-web.smrj.go.jp/customer/skyosai/loan/index_02.html)・いずれも2026年11月16日確認）

### 銀行・信用金庫・信用組合

日本貸金業協会のページでは、貸金業者とは財務局または都道府県に登録してお金を貸し付ける業者で、消費者金融、事業資金を貸し付ける事業者金融、クレジットカード会社などが該当し、銀行・信用金庫・信用組合・労働金庫は「貸金業者」ではないと説明されています。このため、銀行や信用金庫からの借入れは総量規制の対象外です。

総量規制がかからないことは、借りやすいことを意味しません。審査の基準や必要書類は金融機関ごとに異なるため、取引のある金融機関に直接確認します。信用保証協会の保証が付く自治体の制度融資については、[制度融資とは](/articles/article-seido-yuushi/)にまとめています。

### 日本政策金融公庫

日本政策金融公庫の国民生活事業では、個人事業主のインターネット申込に、創業計画書または企業概要書、直近期とその前期の確定申告書一式（青色申告決算書または収支内訳書を含む）、設備資金の場合の見積書、本人確認書類などが必要と案内されています。税務申告が1期だけの方は1期分、事業を始めて間もなく申告が済んでいない方は確定申告書の提出は不要です。

書類の準備の詳細は[確定申告書と融資](/articles/article-kakuteishinkoku-yuushi/)、公庫の制度は[日本政策金融公庫で個人事業主が融資を受ける方法](/articles/article-jfc-kojin/)で扱っています。

### 貸金業者（ビジネスローンなど）

日本貸金業協会は、担保や保証人の有無、消費目的か事業目的かの資金使途にかかわらず、個人向け（個人事業者を含む）の貸付けは原則として総量規制の対象になると説明しています。一方で、個人事業者に対する貸付けは、事業計画・収支計画・資金計画により返済能力を超えないと認められる場合、総量規制の「例外貸付け」として年収の3分の1を超えて借りられます。

「事業用の資金なら総量規制は関係ない」という説明を見かけることがありますが、日本貸金業協会のページでは、総量規制の対象外とされているのは法人向けの貸付けです。個人事業主は原則対象で、例外の手続きがある、という整理になります。ビジネスローンの比べ方は[個人事業主がビジネスローンを比べる手順](/articles/article-business-loan-kojin/)で扱っています。

### 小規模企業共済の契約者貸付

小規模企業共済の加入者は、納付した掛金から算定した貸付限度額の範囲内で借入れができます。一般貸付の条件として、中小機構の小規模企業共済のページには次の内容が書かれています（2026年11月16日確認）。

| 項目 | 公式の記載 |
|------|------|
| 借入資格 | 貸付資格判定時（4月末日・10月末日）までに12か月以上の掛金を納付し、貸付限度額が10万円以上 |
| 貸付限度額 | 掛金の範囲内（掛金納付月数により掛金の7～9割）で、10万円以上2,000万円以内（5万円単位） |
| 使途 | 事業に必要な運転資金、その他事業に関連する資金、または生活資金 |
| 利率 | 年1.5% |
| 担保・保証人 | 不要 |
| 借入窓口 | 登録した代理店（登録がない場合は商工組合中央金庫の本店または支店） |

貸付限度額は年に2回（4月・10月）設定され、判定基準日が4月末なら同年10月1日から、10月末なら翌年4月1日から適用されます。加入して間もない場合は使えないため、今すぐの資金には向きませんが、加入済みの方は最初に確認したい借入先です。

## 審査で何を見られるか（貸金業法の条文から）

貸金業法第13条第1項は、貸金業者に対し、貸付けの契約前に「顧客等の収入又は収益その他の資力、信用、借入れの状況、返済計画その他の返済能力に関する事項」を調査するよう定めています。第2項では、個人の顧客と契約する場合、この調査に指定信用情報機関の信用情報を使用しなければならないとされています（[e-Gov法令検索 貸金業法](https://laws.e-gov.go.jp/law/358AC1000000032)・2026年11月16日確認）。

つまり、貸金業者から借りる場合は、申込みの時点で他社の借入れの状況が信用情報で確認されます。さらに第3項により、その貸金業者からの借入れの合計が50万円を超える場合、または他社を含めた貸金業者からの借入れの合計が100万円を超える場合は、源泉徴収票その他の収入を明らかにする書面の提出が求められます。個人事業主の場合、その書面の代表が確定申告書です。

信用情報に何が記録され、ファクタリングの利用は記録されるのかについては、[ファクタリングが信用情報に登録されない理由](/articles/article-factoring-shinyou-jouhou/)を参照してください。

## 金利の上限と、違法な貸付けの見分け方

### 利息制限法と出資法の上限

利息制限法第1条は、金銭の消費貸借の利息について、次の利率を超える部分を無効としています（[e-Gov法令検索 利息制限法](https://laws.e-gov.go.jp/law/329AC0000000100)・2026年11月16日確認）。

| 元本の額 | 上限の利率 |
|------|------|
| 10万円未満 | 年20% |
| 10万円以上100万円未満 | 年18% |
| 100万円以上 | 年15% |

同法第3条は、礼金・割引金・手数料・調査料など、名目を問わず債権者が受け取る元本以外の金銭を利息とみなすと定めています（契約の締結及び債務の弁済の費用は除く）。「金利は低いが事務手数料が別にかかる」という貸付けでも、手数料を含めて上限を超えていないかを見る必要があるということです。

出資法第5条第2項は、業として金銭の貸付けを行う者が年20%を超える利息の契約をした場合、5年以下の拘禁刑もしくは1,000万円以下の罰金、またはその併科とすると定めています（[e-Gov法令検索 出資の受入れ、預り金及び金利等の取締りに関する法律](https://laws.e-gov.go.jp/law/329AC0000000195)・2026年11月16日確認）。金融庁も、上限金利は利息制限法の水準（貸付け額に応じて15～20%）であると説明しています（[金融庁「貸金業法のキホン」](https://www.fsa.go.jp/policy/kashikin/kihon.html)・2026年11月16日確認）。

### ファクタリングを装った貸付けに注意する

金融庁は、ファクタリングは法的には債権の売買（債権譲渡）契約であるとしたうえで、ファクタリングを装った高金利の貸付けを行うヤミ金融業者の存在を指摘しています。注意喚起のページでは、譲渡した債権の回収を売主が任され、売掛先から集金できなかった場合に売主自身の資金で支払わなければならないとされている取引や、買取代金が債権額に比べて著しく低額である取引を、偽装ファクタリングの疑いがある例として挙げています（[金融庁「ファクタリングの利用に関する注意喚起」](https://www.fsa.go.jp/user/factoring.html)・2026年11月16日確認）。

同じページでは、個人の給与を対象にした「給与ファクタリング」という手法で個人に貸付けを行うヤミ金融の存在にも触れています。事業の売掛金ではなく給与を対象にした取引は、事業資金の調達とは別物です。

### 借りる場合と売る場合の費用を同じ条件で比べる

例：10万円を、利息制限法の上限である年18%で30日間借りた場合、利息は100,000円×18%×30日÷365日で約1,479円です。

例：同じ10万円の請求書を手数料10%で売った場合、手数料は1万円で、受け取るのは9万円（振込手数料は別）です。

この仮定では、借入れのほうが費用は小さくなります。売掛金を売る方法が合うのは、費用よりも次の条件が優先される場面です。

| 状況 | 借入れ | 売掛金の売却 |
|------|------|------|
| 貸金業者からの借入れが総量規制の基準額に達している | 例外貸付けの審査が必要 | 借入れではないため総量規制の計算に入らない |
| 確定申告書がまだない・1期分しかない | 公庫は申告前でも申込み可。貸金業者は収入証明が必要な場合あり | 確定申告書を必要書類に挙げていない会社がある |
| 新たな借入れを増やしたくない | 返済の予定が増える | 売掛先の入金で精算される |
| 請求書がない | 使える | 使えない |

手数料の率が一律でない会社を含めた比較は[ファクタリングとビジネスローンの違い](/articles/article-factoring-vs-business-loan/)、手数料が利息制限法の対象になるかどうかは[ファクタリングと利息制限法の関係](/articles/article-factoring-risoku-seigen/)で扱っています。

## 状況別の借入先の選び方

| 状況 | 最初に確認する先 | 確認すること |
|------|------|------|
| 小規模企業共済に12か月以上加入している | 共済の契約者貸付 | 貸付限度額（毎年3月に届くお知らせに記載） |
| 申告2期分がそろい、入金まで待てる | 日本政策金融公庫・取引のある金融機関 | 申込みに必要な書類と、入金までの日程 |
| 開業前・申告前 | 日本政策金融公庫の創業向けの相談 | 創業計画書の準備 |
| 貸金業者から借りる | 貸金業の登録の有無、利率が上限内か | 手数料を含めた実際の負担、総量規制の残り |
| 請求書がある | ファクタリング会社の公式の手数料・必要書類 | 手数料の率、売掛先への通知の有無 |

創業時の資金は[創業融資のガイド](/articles/article-sogyo-yushi/)、融資・ファクタリング・補助金を含めた全体の選び方は[個人事業主の資金調達](/articles/article-kojin-shikin-chotatsu/)にまとめています。

## よくある質問

**Q: 個人事業主がビジネスローンで事業資金を借りる場合も、総量規制の対象ですか？**

A: 日本貸金業協会の説明では、個人事業者に対する貸付けは原則として総量規制の対象です。ただし、事業・収支・資金計画を提出し、返済能力があると認められる場合は、年収の3分の1を超えて借りられる「例外貸付け」があります。総量規制の対象外とされているのは法人向けの貸付けです。

**Q: 銀行のカードローンは総量規制の対象になりますか？**

A: 日本貸金業協会は、総量規制は貸金業者からの借入れを対象としているため、銀行・信用金庫・信用組合・労働金庫などからの借入れは対象外と説明しています。

**Q: 小規模企業共済に入ったばかりでも借りられますか？**

A: 一般貸付は、貸付資格判定時（4月末日・10月末日）までに12か月以上の掛金を納付し、貸付限度額が10万円以上であることが要件です。加入直後は利用できません。

**Q: 「手数料」の名目なら、利息制限法の上限を超えてもよいのですか？**

A: 利息制限法第3条は、金銭の消費貸借に関して債権者が受け取る元本以外の金銭は、手数料・調査料など名目を問わず利息とみなすと定めています（契約の締結及び債務の弁済の費用を除く）。借入れであれば、手数料を含めて上限を超えていないかを確認します。

## まとめ

- 借入先は、銀行・信用金庫等、日本政策金融公庫、貸金業者、小規模企業共済の契約者貸付に分かれ、規制と書類が違う
- 総量規制は貸金業者の個人向け貸付けに適用され、個人事業主も原則対象。事業計画等による例外貸付けがある
- 金利は利息制限法で元本に応じ年15〜20%が上限。手数料などの名目でも利息とみなされる
- 請求書があれば売掛金の売却も比べられる。短期の費用は上限金利内の借入れより大きくなることが多いため、総量規制・書類・借入れを増やしたくない事情など、条件で選ぶ
