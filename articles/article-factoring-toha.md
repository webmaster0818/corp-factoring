ファクタリングという言葉は知っているものの、具体的な内容がわからないという方に向けて解説します。

ファクタリングは、**手持ちの請求書を売却し、入金日を待たずに現金を受け取れるサービス**です。借入ではないため、信用情報にも影響しません。

この記事では、ファクタリングの仕組み・手数料・メリット・デメリットを、**図解と具体的な金額の例を用いて、初めての方にもわかりやすく**解説します。

---

## ファクタリングの概要

**ファクタリングとは、請求書の代金を前倒しで受け取るサービスです**

通常、取引先に請求書を発行すると、入金は30日〜60日後です。ファクタリングを利用すれば、**その請求書をファクタリング会社に売却し、最短即日で現金化**できます。

### 具体例

Webデザイナーが、A社に50万円の請求書を発行したとします。

**ファクタリングなし:**
- 4月1日: 請求書発行
- 5月31日: A社から50万円入金（60日後）

**ファクタリングあり:**
- 4月1日: 請求書発行
- 4月1日: ファクタリング会社に請求書を売却
- 4月1日: 手数料5万円（10%）を差し引いた**45万円が即日で入金**
- 5月31日: A社からの50万円は、ファクタリング会社が回収

**結果:** 60日待たずに、45万円を即日で受け取れます。手数料5万円は、時間を短縮するための費用です。[ファクタリング手数料の相場と安くする方法](/articles/article-factoring-tesuryo/)もあわせてご覧ください。

## ファクタリングの仕組み【2社間と3社間】

### 2社間ファクタリング（売掛先に知られない）

**関係者:** 利用者 ＋ ファクタリング会社（2者）

**流れ:**
1. 利用者がファクタリング会社に請求書を提出する
2. ファクタリング会社が審査する（売掛先の信用力を確認）
3. 手数料を差し引いた金額が、利用者に振り込まれる
4. 入金日に、A社から利用者に入金される
5. 利用者がファクタリング会社に送金する

2社間ファクタリングでは、売掛先（A社）にファクタリングの利用が知らされません。取引関係に影響はありません。

| 項目 | 内容 |
|------|------|
| 手数料 | 8〜18% |
| スピード | 最短即日 |
| 売掛先への通知 | なし |
| メリット | 知られない・入金が早い |
| デメリット | 手数料が高い |

### 3社間ファクタリング（手数料が低い）

**関係者:** 利用者 ＋ ファクタリング会社 ＋ 売掛先（3者）

**流れ:**
1. 利用者がファクタリング会社に請求書を提出する
2. ファクタリング会社が、売掛先に「債権譲渡の通知」を送付する
3. 売掛先が承諾する
4. 手数料を差し引いた金額が、利用者に振り込まれる
5. 入金日に、売掛先がファクタリング会社に直接支払う

3社間ファクタリングでは売掛先の承諾が必要なため、ファクタリングの利用が取引先に知られます。

| 項目 | 内容 |
|------|------|
| 手数料 | 2〜9% |
| スピード | 数日〜1週間 |
| 売掛先への通知 | あり |
| メリット | 手数料が低い |
| デメリット | 取引先に知られる・時間がかかる |

### どちらを選ぶべきか

| 利用者の状況 | おすすめ |
|------------|---------|
| 取引先に知られたくない | 2社間 |
| できるだけ手数料を抑えたい | 3社間 |
| 当日中に現金が必要 | 2社間 |
| 取引先が大企業で理解がある | 3社間 |

**判断に迷う場合は、2社間を選ぶほうが無難です。** 取引先との関係を保ちながら、資金を調達できます。

## ファクタリングの手数料

### 手数料の相場

| 形態 | 手数料の目安 |
|------|----------|
| 2社間 | 8〜18%程度 |
| 3社間 | 2〜9%程度 |

上の目安は、[トップ・マネジメントの公式FAQ](https://top-management.co.jp/faq/)が「一般的に」として示している範囲です（2026年10月31日確認）。各社の公式表示は[手数料比較](/fees/)で確認できます。

### 手数料が決まる要素

1. **売掛先の信用力:** 大企業・上場企業であれば低い
2. **売掛金の金額:** 大きいほど低い
3. **入金期日までの日数:** 近いほど低い
4. **利用回数:** 継続して利用するほど低い
5. **契約形態:** 3社間のほうが低い

### 手数料の具体例

**100万円の請求書の場合:**

| パターン | 手数料率 | 手数料 | 手取り |
|---------|---------|--------|--------|
| 2社間・初回・中小企業宛て | 15% | 15万円 | 85万円 |
| 2社間・2回目・上場企業宛て | 8% | 8万円 | 92万円 |
| 3社間・大企業宛て | 3% | 3万円 | 97万円 |

## ファクタリングの5つのメリット

### 1. 最短即日で現金化できる

銀行融資は2〜4週間、ビジネスローンでも即日〜数日かかります。ファクタリングであれば、**最短即日**で口座に入金されます。[即日対応のファクタリング会社](/articles/article-factoring-sokujitsu/)もご確認ください。

### 2. 信用情報に影響しない

ファクタリングは「借入」ではなく「債権の売却」です。CICやJICCなどの信用情報機関に記録されないため、将来の住宅ローンや事業融資にも影響しません。

### 3. 審査に通過しやすい

融資の審査では申込者の返済能力が確認されますが、ファクタリングの審査では、**売掛先（取引先）の支払い能力**が確認されます。赤字でも、税金の滞納があっても、売掛先の信用力が高ければ利用できます。

### 4. 売掛金の未回収リスクがなくなる

ファクタリング（ノンリコース契約）の場合、売掛先が倒産して支払い不能になっても、**利用者がファクタリング会社に返金する義務はありません。** 未回収のリスクを、ファクタリング会社に移転できます。

### 5. 担保・保証人が不要

ファクタリングでは、担保や保証人は一切不要です。請求書があれば利用できます。

## ファクタリングの4つのデメリット

### 1. 手数料がかかる

2社間で8〜18%、3社間で2〜9%の手数料がかかります。銀行融資（年1〜3%）と比べると、費用は高めです。ただし、**急ぎで現金が必要な状況への対価**と考えれば、妥当な場合も多くあります。

### 2. 売掛金の金額以上は調達できない

融資であれば数百万〜数千万円の調達が可能ですが、ファクタリングは**手持ちの請求書の合計額が上限**です。100万円の請求書しかない場合は、最大100万円（実際は手数料を差し引いた額）しか調達できません。

### 3. 3社間では取引先に知られる

3社間ファクタリングを利用すると、売掛先に「債権譲渡通知」が届きます。資金繰りが厳しいと受け取られるリスクがあります。この点を懸念する場合は、2社間を選んでください。

### 4. 悪質業者が存在する

ファクタリング業界には、貸金業のような厳格な規制がないため、ファクタリングを装った闇金業者が存在します。以下に該当する業者は避けてください。

- 手数料が30%以上
- 「審査なし」をうたっている
- 契約書を交付しない
- 担保・保証人を要求する
- 償還請求権ありの契約を強要する

## ファクタリングは違法か：合法です

**ファクタリングは合法です。** 民法第466条の「債権譲渡」に該当する正当な取引であり、金融庁も、事業者の資金調達の一手段であり法的には債権の売買（債権譲渡）契約であると説明しています（出典：[金融庁「ファクタリングの利用に関する注意喚起」](https://www.fsa.go.jp/user/factoring.html)）。

ただし、**「給与ファクタリング」は違法です。** 個人の給与を対象としたファクタリングは、実質的な貸付行為として、金融庁が違法と判断しています。本記事で解説しているのは、事業者向けの正規のファクタリングです。

## ファクタリングの利用手順（4ステップ）

### STEP1: 申込（5分）
オンラインで、請求書・本人確認書類・通帳をアップロードします。

### STEP2: 審査（最短即日）
ファクタリング会社が、売掛先の信用力を審査します。AI審査であれば、最短即日で完了します。

### STEP3: 契約（電子契約）
手数料率・入金額・条件を確認して契約します。必ず、**償還請求権なし（ノンリコース）**であることを確認してください。

### STEP4: 入金
契約の完了後、指定口座に振り込まれます。最短即日です。

## ファクタリングの種類一覧

| 種類 | 内容 | 対象 |
|------|------|------|
| **買取型** | 売掛金を売却して現金化 | 一般企業・個人事業主 |
| **保証型** | 売掛金の未回収リスクを保証 | 取引先の与信管理 |
| **診療報酬ファクタリング** | 診療報酬債権を現金化 | 医療機関 |
| **介護報酬ファクタリング** | 介護報酬債権を現金化 | 介護施設 |
| **注文書ファクタリング** | 受注段階で現金化（納品前） | 建設業等 |
| **国際ファクタリング** | 海外取引の売掛金を現金化 | 貿易業 |

本記事で主に解説しているのは、**買取型ファクタリング**です。最も一般的な形態で、個人事業主やフリーランスが利用するのは、ほぼこのタイプです。

## ファクタリングの利用に適した人・適さない人

### 利用に適した人

- 請求書があり、入金日前に現金が必要な方
- 銀行融資の審査に通過しなかった方
- 信用情報に影響を与えたくない方
- 取引先の入金サイトが長い方（60日以上）
- 赤字だが、売掛金はある方

### 利用に適さない人
- 請求書（売掛金）がない方
- 請求書（売掛金）がない
- 2〜3週間待てる方 → [日本政策金融公庫の低金利融資](/articles/article-jfc-kojin/)のほうが有利
- 手数料の負担を避けたい方 → [補助金・助成金](/articles/article-kojin-hojokin/)を検討
- 恒常的に資金が不足している方 → ファクタリングは一時的な資金繰りの改善策であり、根本的な経営の改善が必要

## よくある質問

### Q. ファクタリングと借入の違いは何ですか？

**A. ファクタリングは「売却」、借入は「借入」です。** ファクタリングは返済が不要で、信用情報に影響しません。借入は毎月の返済が必要で、信用情報に記録されます。

### Q. 個人事業主・フリーランスでも利用できますか？

**A. 利用できます。** ペイトナー、ラボル、FREENANCEなど、個人事業主・フリーランス向けのサービスが多数あります。1万円から利用できるサービスもあります。

### Q. どのような請求書でも利用できますか？

**A. 基本的には、法人宛ての請求書が対象です。** ペイトナーは、個人間の取引にも利用できると公式FAQに記載しています。ラボルは、法人が取引先となる請求書のみを買い取ると公式FAQに記載しています（2026年10月18日確認）。また、すでに支払期限を過ぎた請求書は利用できません。

### Q. 確定申告では、どのように処理しますか？

**A. 手数料は「売上債権売却損」として経費に計上します。** ファクタリングで受け取った金額は、元の売上の一部です。手数料分のみを、損失として計上します。消費税は非課税です。

### Q. 税金はかかりますか？

**A. ファクタリング手数料に、消費税はかかりません。** 金銭債権の譲渡は、消費税法上の非課税取引に該当します。

### Q. ファクタリング会社に支払わないと、どうなりますか？

**A. 2社間ファクタリングの場合、入金日に売掛先から受け取った代金を、ファクタリング会社に送金する義務があります。** これを怠ると契約違反となり、法的措置をとられる可能性があります。

## まとめ

**ファクタリングは、請求書を持っている事業者が利用できる、即日での資金化サービスです。**

- 借入ではない → 信用情報に影響しない
- 最短即日で入金 → 急な資金需要に対応
- 審査は売掛先が基準 → 赤字でも利用できる

**初めて利用する場合は：** ビートレーディング（累計91,000社の実績）またはペイトナー（最短即日）に、無料見積もりを依頼することをおすすめします。見積もりのみであれば、費用はかかりません。
