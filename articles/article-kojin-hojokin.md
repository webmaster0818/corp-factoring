# 個人事業主の補助金・助成金｜公募中の制度と後払いの間の資金のつなぎ方

**対策KW:** 個人事業主 補助金
**メタdescription:** 個人事業主も補助金・助成金を使えますが、審査があり、支払いは事業の後の精算払いが原則です。持続化補助金第20回（締切2026年12月15日）など公式で確認した制度の要件と、立替期間の資金のつなぎ方を整理しました。
**想定文字数:** 6,500字
**ステータス:** 下書き

---

個人事業主も補助金・助成金を使えますが、補助金には審査があり、支払いは事業を実施して検査を受けた後の「後払い（精算払い）」が原則のため、対象の経費はいったん自分で立て替える必要があります。2026年11月16日に公式ページで確認した時点では、小規模事業者持続化補助金（一般型・通常枠）の第20回が2026年12月15日17時まで申請を受け付けており、デジタル化・AI導入補助金2026の交付申請期限は2027年1月7日17時と案内されています。

この記事では、公式ページを開いて確認できた制度だけを取り上げ、要件・金額・期限を公式の記載どおりに整理します。後半では、採択から入金までの立替期間の資金を、融資や手元の売掛金でどうつなぐかを、当サイトが各社公式で確認したデータとあわせて示します。

## 補助金の基本：返済不要だが、審査があり後払い

中小企業庁のミラサポplusは、補助金について次のように説明しています（[ミラサポplus「補助金とは」](https://mirasapo-plus.go.jp/subsidy/guide/)・2026年11月16日確認）。

- 融資とは異なり、原則として返済の必要がない
- 経費の全額が補助されるとは限らず、補助対象経費・補助の割合・上限額が決まっている
- 補助の有無や金額は「事前の審査」と「事後の検査」で決まる
- 原則、補助金は後払い（精算払い）で、事業の実施後に必要書類を提出して検査を受けた後に受け取る

ミラサポplusの「補助金入門」では、手続きの流れを、審査を経て「採択」、交付申請を経て「交付決定」、事業の終了後に実績報告と検査、補助金額の決定、事業者からの請求、という順で説明しています。交付決定の前に発注した経費は補助の対象外で、契約を結んだだけでも対象外になると書かれています（[ミラサポplus「補助金入門 STEP3」](https://mirasapo-plus.go.jp/hint/25788/)・2026年11月16日確認）。

補助金と助成金、ファクタリングの違いを整理した記事は[ファクタリングと補助金・助成金の違い](/articles/article-factoring-hojokin-chigai/)です。

## 小規模事業者持続化補助金（一般型・通常枠）第20回

### 公募要領に書かれている主な条件

商工会議所地区の事務局サイトで公開されている第20回の公募要領（第9版）の内容です（[商工会議所地区 小規模事業者持続化補助金](https://r6.jizokukahojokin.info/)・公募要領第9版・2026年11月16日確認）。公募要領は商工会地区（株式会社ニューズベース）と商工会議所地区（株式会社日本経営データ・センター）の両事務局の名前で出されており、商工会地区の事務局サイトは[official.jizokukanb.com](https://official.jizokukanb.com/)です。

| 項目 | 公募要領の記載 |
|------|------|
| 補助上限 | 50万円。インボイス特例は50万円、賃金引上げ特例は150万円、両方の特例は200万円を上乗せ（要件あり） |
| 補助率 | 2/3以内（賃金引上げ特例のうち赤字事業者は3/4以内） |
| 対象経費 | 機械装置等費、広報費、ウェブサイト関連費、展示会等出展費、旅費、新商品開発費、借料、委託・外注費 |
| 申請受付 | 2026年11月5日（木）〜2026年12月15日（火）17:00 |
| 事業支援計画書（様式4）の発行受付締切 | 2026年12月4日（金） |
| 申請方法 | 電子申請システムのみ（郵送不可）。GビズIDプライムのアカウントが必要 |
| 支払い | 補助事業の遂行には自己負担が必要で、補助金は後払い |

様式4は地域の商工会・商工会議所が発行する書類で、公募要領は締切以降の発行依頼はいかなる理由でも受けないとしています。申請の締切より前に様式4の締切が来る点に注意が必要です。

### 対象になる「小規模事業者」

| 業種 | 常時使用する従業員の数 |
|------|------|
| 商業・サービス業（宿泊業・娯楽業除く） | 5人以下 |
| サービス業のうち宿泊業・娯楽業 | 20人以下 |
| 製造業その他 | 20人以下 |

（出典：同上の公募要領）

### 個人事業主が出す確定申告書

公募要領の提出書類の一覧では、個人事業主は直近の確定申告書（第一表、第二表、および収支内訳書（1・2面）、または第一表、第二表、および所得税青色申告決算書（1〜4面））の写しを出すとされています。確定申告を一度も行っていない場合だけ、開業日の記載がある開業届の写しと、開業以降売上が発生していることを示す売上台帳等の写しで代えられます。開業後に一度でも申告していれば、所得額に関わらず確定申告書の写しが必要です。

### 経費の支払いで気をつけること

公募要領では、補助対象の経費は「交付決定日以降に発生し補助事業期間中に支払が完了した経費」で、証憑資料等で支払金額を確認できるものに限るとされています。対象外の経費として、交付決定前に発注・契約・購入・支払い（前払いを含む）をしたもの、小切手・手形・相殺による決済・支払いなどが挙げられています。

つまり、交付決定の後に発注し、補助事業期間が終わる前に現金や振込で支払いを済ませておく必要があります。支払いのための資金は、補助金の入金より前に用意しなければなりません。

## デジタル化・AI導入補助金（旧IT導入補助金）通常枠

デジタル化・AI導入補助金の公式サイトでは、通常枠について次のように案内されています（[デジタル化・AI導入補助金2026 通常枠](https://it-shien.smrj.go.jp/applicant/subsidy/normal/)・2026年11月16日確認）。

| 項目 | 公式の記載 |
|------|------|
| 補助対象者 | 中小企業・小規模事業者等 |
| 補助率 | 1/2以内。令和7年10月から令和8年9月までの間で3か月以上、令和8年度改定の地域別最低賃金未満で雇用している従業員が全従業員の30%以上であることを示した場合は2/3以内 |
| 補助額 | 1プロセス以上：5万円以上150万円未満／4プロセス以上：150万円以上450万円以下 |
| 補助対象 | ソフトウェアが必須。ソフトウェア購入費、クラウド利用料（最大2年分）など |

公式サイトのお知らせ（2026年10月30日更新）では、デジタル化・AI導入補助金2026の交付申請期限は1月7日（木）17:00とされています。2027年1月から受付を始める「スマートレジ類型」「POSレジ類型」にはこの締切は適用されず、別途案内するとしています。

## 業務改善助成金（厚生労働省）

業務改善助成金は、生産性向上に資する設備投資等を行い、事業場内最低賃金を一定額以上引き上げた場合に、設備投資などにかかった費用の一部を助成する制度です。助成額は、費用に助成率をかけた金額と助成上限額のいずれか安いほうです（[厚生労働省「業務改善助成金」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/zigyonushi/shienjigyou/03.html)・2026年11月16日確認）。

個人事業主にとって重要なのは、同じページの次の記載です。

- 事業場内最低賃金の引上げや設備投資等は、これから実施するものが助成の対象
- 労働者（従業員）の事業場内最低賃金を引き上げるための制度であるため、労働者（従業員）がいない場合は対象とならない
- 令和8年度の申請期間は、令和8年9月1日から、申請事業場の都道府県の地域別最低賃金の発効日の前日、または同年11月30日のいずれか早い日まで（都道府県によっては9月末が期限）

従業員を雇わずに一人で事業をしている場合は対象になりません。従業員がいる場合も、2026年度分は最も遅い場合でも11月30日が期限で、都道府県によってはすでに締め切られています。

## 申請の前に：GビズIDプライム

持続化補助金の申請にはGビズIDプライムのアカウントが必要です。GビズIDのよくある質問では、取得までの期間が次のように案内されています（[GビズID よくある質問](https://gbiz-id.go.jp/top/faq/faq.html)・2026年11月16日確認）。

| 申請方法 | 必要なもの | 発行までの期間 |
|------|------|------|
| オンライン申請 | マイナンバーカード、マイナンバーカードを読み取れるスマートフォン（SMS受信・NFC対応）、申請用端末 | 即日〜数日（最短で即日発行） |
| 書類郵送申請 | 印鑑（登録）証明書、登録印、申請用端末、SMSを受信できる電話、プリンタ | 書類到着・不備なしの場合、最大1か月以内 |

個人事業主が取得できるGビズIDプライムのアカウントは1つです。マイナンバーカードがあればオンラインで早く取れますが、郵送の場合は最大1か月かかるため、公募の締切が近いときは申請方法を先に決めておきます。

## 後払いの間の資金をどうつなぐか

### 立て替える額の考え方

例：持続化補助金（通常枠・補助率2/3・上限50万円）で、補助対象経費が75万円の場合、補助金は50万円です。交付決定の後に75万円を支払い、実績報告と検査を経て補助金が入るまで、75万円全額を立て替えます。最終的な自己負担は25万円です。

この立替を、資金繰り表の上でいつ支払い、いつ補助金が入るかとして書いておくと、不足する月が見えます。書き方は[資金繰り表の作り方](/articles/article-shikin-gurihyou/)で扱っています。

### つなぎ方の比較

| 方法 | 合う状況 | 注意点（公式の記載から） |
|------|------|------|
| 自己資金 | 立替額を手元資金でまかなえる | 補助事業期間中に支払いを完了させる必要がある |
| 融資（公庫・金融機関） | 交付決定の時期が見えていて、申込みから入金まで待てる | 公庫は確定申告書一式2期分などが必要（[確定申告書と融資](/articles/article-kakuteishinkoku-yuushi/)） |
| 手元の売掛金を売る（ファクタリング） | 取引先への請求書があり、支払期限までに資金を用意したい | 売る債権は補助金ではなく、事業の売掛金。手数料がかかる |

補助金は採択の時点で予定が立つため、支払いの時期もあらかじめ分かります。売掛金を売る場合も、売掛先に知らせない2社間だけでなく、日程に余裕を持って売掛先の承諾を得る3社間も選びやすくなります。下の表のとおり、多くの会社の公式表示では3社間の手数料の下限が2社間より低く設定されています。

### 3社間に対応し、個人事業主が使える会社の手数料（公式表示）

## よくある質問

**Q: 補助金は申請して採択されれば、すぐに入金されますか？**

A: されません。ミラサポplusは、補助金は原則として後払い（精算払い）で、事業の実施後に必要書類を提出し検査を受けた後に受け取ると説明しています。採択の後に交付申請と交付決定があり、交付決定の前に発注した経費は対象外です。

**Q: 開業したばかりで確定申告をしていませんが、持続化補助金に申請できますか？**

A: 第20回の公募要領では、確定申告を一度も行っていない場合に限り、開業日の記載がある開業届の写しと、開業以降に売上が発生していることを示す売上台帳等の写しを、確定申告書の代わりに提出するとされています。

**Q: 従業員がいない個人事業主でも、業務改善助成金を使えますか？**

A: 厚生労働省のページでは、労働者（従業員）の事業場内最低賃金を引き上げるための制度であるため、労働者がいない場合は対象とならないとされています。

**Q: GビズIDプライムは、どのくらいで取れますか？**

A: GビズIDのよくある質問では、マイナンバーカードを使うオンライン申請は即日〜数日（最短で即日）、書類郵送申請は書類の到着後、不備がなければ最大1か月以内とされています。

**Q: 補助金の入金を待つ間に、補助金そのものを売って資金にできますか？**

A: この記事で取り上げたファクタリング会社の公式データは、事業の売掛金（請求書）を対象としたものです。補助金の受取りを対象にした取扱いは当サイトでは確認していません。立替資金には、自己資金、融資、手元の売掛金の売却を検討します。

## まとめ

- 補助金は原則返済不要だが、審査があり、交付決定の後に支払った経費が事業の後に精算される後払い
- 持続化補助金第20回は、申請締切が2026年12月15日17時、様式4の発行受付締切が12月4日。上限50万円（特例で上乗せ）、補助率2/3以内
- デジタル化・AI導入補助金2026の交付申請期限は2027年1月7日17時（スマートレジ・POSレジ類型を除く）
- 業務改善助成金は従業員がいない場合は対象外。令和8年度の申請期限は最も遅くても11月30日
- 立替期間の資金は、支払い時期が分かる分、融資や3社間ファクタリングなど日程に余裕のある方法も選べる
