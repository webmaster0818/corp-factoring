# 支払いが間に合わない時の初動｜今日・今週でできる資金確保の優先順位

**対策KW:** 支払い 間に合わない 会社, 支払い 間に合わない 対処, 支払い 優先順位
**メタdescription:** 支払いが間に合わないと分かった日は、まず期日と不足額を一覧にし、手形・でんさいと給与を守り、税・社会保険は猶予を申請、借入・仕入・家賃は期日前に相談します。今日・今週の行動順を制度の根拠とあわせて説明します。
**想定文字数:** 6,500字
**ステータス:** 下書き

---

支払いが間に合わないと分かった時点で最初に行うことは、資金を探すことではなく、今後の支払いを期日順に並べ、期日を動かせない支払いと相談や申請で動かせる支払いに分けることです。手形・でんさいの決済と給与は期日どおりに支払う前提で資金を寄せ、税金・社会保険料は滞納する前に猶予制度を申請し、借入返済・仕入代金・家賃は期日の前に相手方へ相談します。資金を確保する手段（売掛金の早期資金化、ファクタリング、日本政策金融公庫の融資）は、この整理を終えてから不足額に合わせて選びます。

当サイトでは、支払いの種類ごとに「期日に払えなかった場合に何が起きるか」「公的な猶予制度や相談先があるか」を、全国銀行協会・国税庁・日本年金機構などの一次情報で確認し、優先順位の目安として整理しています。

| | 今日できること | 今週できること |
|---|---|---|
| 現状の把握 | 預金残高と、今後30日の支払い・入金を期日順に一覧にする | 資金繰り表を3か月分に広げ、不足が続く月を確認する |
| 期日を動かせない支払い | 手形・でんさいの決済日と金額を確認し、決済口座の残高を優先して確保する | 給与の支払日までの資金計画を確定する |
| 税金・社会保険料 | 納期限を確認し、所轄の税務署（徴収担当）・年金事務所に電話で相談する | 換価の猶予などの申請書を提出する（国税はe-Tax・郵送も可） |
| 借入返済・仕入・家賃 | 期日が近い相手から順に、支払日の変更や分割を相談する | 金融機関と返済条件の変更を協議する。合意内容を書面に残す |
| 入金の前倒し | 売掛先に支払日の前倒しが可能か打診する。請求書・通帳の写しをそろえる | 売掛金がある場合はファクタリングの見積もりを複数社から取る |
| 融資 | 日本政策金融公庫の制度の対象になるかを確認する | 公庫・取引金融機関に融資を申し込む |

## 最初の1時間で作る「支払い一覧」

優先順位を決めるには、何をいつまでにいくら払うのかが一覧になっている必要があります。会計ソフトや資金繰り表がなくても、次の5項目を並べるだけで初動の判断には足ります。

| 記入する項目 | 記入の例 | 確認する資料 |
|---|---|---|
| 支払先・種類 | 源泉所得税、社会保険料、仕入先A社、事務所家賃、銀行返済 | 請求書、納付書、返済予定表 |
| 期日 | 10日、月末、手形・でんさいの支払期日 | 契約書、手形の控え、でんさいの記録 |
| 金額 | 支払う金額（分割が可能なら1回分も） | 同上 |
| 相談・申請の余地 | 猶予制度あり／相手方と交渉可／期日変更不可 | 本記事の次の表 |
| 入金予定 | 売掛先ごとの入金日と金額 | 請求書の控え、入金予定表 |

一覧を作ると、「今月は不足するが来月には回復する」のか、「数か月にわたって不足が続く」のかが分かります。前者であれば支払日の調整と短期の資金化で乗り切れる可能性があり、後者であれば融資や返済条件の変更など、より長い期間を見た手当てが必要になります。3か月以上の見通しを立てる方法は[資金繰り表の作り方](/articles/article-shikin-gurihyou/)をご覧ください。

## 支払いの種類別の優先順位

支払いを止めた場合の影響は、種類によって大きく異なります。当サイトでは、次の2つの観点で優先順位を整理しています。

- 期日に払えなかった場合の影響が、取引全体や事業の継続に及ぶか
- 公的な猶予制度や、期日前の相談で支払日を変更できる余地があるか

| 支払いの種類 | 期日に払えなかった場合に起きること | 猶予制度・相談先 | 初動の目安 |
|---|---|---|---|
| 手形・でんさいの決済 | 6か月以内に2回目の不渡・支払不能があると、取引停止処分（2年間、金融機関の貸出取引などが制限される） | 制度上の猶予はない（期日どおりの決済が前提） | 最優先で決済口座の残高を確保する |
| 給与 | 労働基準法24条に反する（賃金の全額・毎月1回以上・一定期日払い） | 制度上の猶予はない | 最優先で資金を確保する |
| 国税（源泉所得税・法人税・消費税など） | 延滞税が納期限の翌日から発生する | 換価の猶予・納税の猶予（所轄の税務署の徴収担当） | 納期限前に相談・申請する |
| 社会保険料（厚生年金保険料・健康保険料） | 督促状の送付を受け、指定期限を過ぎると延滞金が発生することがある | 換価の猶予・納付の猶予（管轄の年金事務所） | 納期限前に相談・申請する |
| 借入返済 | 契約の定めによる（遅延損害金などの条項を確認する） | 取引金融機関との返済条件の変更 | 期日前に相談する |
| 仕入代金・外注費 | 取引の停止・条件の変更につながるおそれがある | 支払先との個別の合意 | 期日前に相談する |
| 家賃・リース料 | 契約の定めによる | 貸主・リース会社との個別の合意 | 期日前に相談する |

### 手形・でんさいの決済は最優先

自社が約束手形の振出人、またはでんさいの債務者である場合、決済日の口座残高は最も優先して確保します。全国銀行協会の電子交換所規則では、不渡報告に掲載された者が、1回目の不渡手形の交換日から6か月以内に2回目の不渡を出すと取引停止処分に付され、参加銀行は処分日から2年間、その者と当座勘定および貸出の取引をすることができないと定めています（電子交換所規則第39条・第42条）。

でんさいについても、でんさいネットは「債務者が6か月以内に2回以上支払不能でんさいを生じさせた場合」に、債務者としての利用と参加金融機関との貸出取引を2年間禁止する取引停止処分を設けています。手形・でんさいは期日どおりの決済が前提であり、不渡・支払不能の影響が銀行取引全体に及ぶため、他の支払いより先に資金を寄せる対象になります。

### 給与は期日どおりに支払う前提で組み立てる

労働基準法24条は、賃金を通貨で直接、全額を支払うことと、毎月1回以上、一定の期日を定めて支払うことを定めています。税金や借入返済のような猶予の制度はないため、給与は支払う前提で資金計画を組み立てます。給与の支払いに不足が出る場合の具体的な対応は、[給料が払えない会社が給与日までにできること](/articles/article-factoring-kyuryo-haraenai/)をご覧ください。

### 税金・社会保険料は「払わない」のではなく「猶予を申請する」

税金と社会保険料は、滞納すると延滞税・延滞金がかかる一方で、申請による猶予制度が整っている支払いです。納期限を過ぎてから放置するのではなく、納期限の前に相談・申請することで、分割での納付が認められる可能性があります。詳しい制度は次の章で説明します。

### 借入返済・仕入代金・家賃は期日前に相談する

この3つは、相手方との合意によって支払日や金額を変えられる余地がある支払いです。ただし、合意は期日の前に求めるほうが応じてもらいやすく、期日を過ぎてからの連絡は信用の低下につながります。仕入代金・外注費の相談の進め方は、[仕入れ代・外注費が払えない時の対処法](/articles/article-gaichuhi-haraenai/)で詳しく扱っています。

## 税金・社会保険料の猶予制度

### 国税の換価の猶予・納税の猶予

国税庁の「国税の納税の猶予制度FAQ」（令和6年11月）では、国税の猶予制度を「期限内の納付が難しい場合に、申請により税務署長の許可を受けて、原則として１年以内の期間に限り、分割して納付することができるようになる制度」と説明しています。法人税・源泉所得税・申告所得税・消費税などの相談先は、所轄の税務署の徴収担当です。

主な制度は次の2つです。

| | 換価の猶予 | 納税の猶予 |
|---|---|---|
| 主な要件 | 一時に納付すると事業の継続・生活の維持が困難となるおそれがあり、納税について誠実な意思があること | 災害・盗難、病気、事業の休廃業、利益の減少等による著しい損失などにより、一時に納付できないこと |
| 申請期限 | 納期限から6か月以内 | FAQの要件欄に期限の記載なし（所轄の税務署に確認） |
| 他の滞納 | 猶予を受けようとする国税以外に滞納がないこと | 他に滞納があっても申請できる |
| 延滞税 | 軽減 | 免除または軽減 |
| 担保 | 原則必要。ただし、猶予額100万円以下、猶予期間3か月以内、提供できる担保がない場合は不要 | 同左 |

同FAQは、延滞税が納期限の翌日から発生すること、換価の猶予の申請が納期限を過ぎると、納期限の翌日から申請日の前日までは延滞税が軽減されないことを示し、早めの申請を勧めています。猶予が認められた場合、延滞税の軽減（納税の猶予は免除または軽減）は、許可された日ではなく申請日から適用されます。黒字であっても要件を満たせば猶予を受けられること、申請書はe-Taxまたは郵送でも提出できることも記載されています。

「一時に納付が困難」かどうかは、手元資金から当面の資金繰りに必要な額を差し引いた納付可能金額が、納付すべき国税の額に満たないかで判断されます。同FAQは、一般的には事業継続のため1か月以内に支出が予定されている金額を運転資金として納税資金から除外するとしています。冒頭で作った支払い一覧は、この説明にもそのまま使えます。

なお、住民税や固定資産税などの地方税は都道府県・市区町村、労働保険料は都道府県労働局が相談先であると、同FAQに記載されています。

### 社会保険料の換価の猶予・納付の猶予

日本年金機構は、健康保険料・厚生年金保険料について、換価の猶予と納付の猶予を設けています。換価の猶予は、保険料等を一時に納付することで事業の継続または生活の維持を困難にするおそれがあり、納付に対する誠実な意思があると認められる場合に、納期限から6か月以内に申請することで、一定の期間内に分割して納付できる制度です。延滞金について、同機構は「猶予期間における延滞金の一部が免除」されると案内しています。

納付の猶予は、災害等によって事業所の財産に相当な損害を受けた場合などが対象で、猶予期間中の延滞金は全部または一部が免除されます。いずれも相談先は管轄の年金事務所です。

## 借入返済は金融機関に条件変更を相談する

金融庁は、令和7年11月27日の金融関係団体への要請「金融の円滑化に向けた取組及び事業者支援の徹底について」で、「既往債務の条件変更や借換え等については、引き続き、申込みを断念させるような対応を取らないことは勿論のこと、事業者に寄り添った迅速かつ柔軟な対応を継続すること」を求めています。

返済が難しいと分かった段階で、返済日の前に取引金融機関へ相談します。相談の際は、支払い一覧と、不足がいつ解消する見込みかを示す資料を持参すると話が進みやすくなります。借入の契約書（銀行取引約定書など）には、返済が遅れた場合の扱いが定められているため、相談の前に該当する条項を確認しておきます。

## 資金を確保する手段の比較

支払いの順番と相談先を整理したうえで、それでも不足する金額を埋める手段を選びます。手段ごとに、資金が届くまでの時間と、使える条件が異なります。

| 手段 | 使える条件 | 資金化までの時間の目安 | 留意点 |
|---|---|---|---|
| 売掛先への支払日の前倒しの依頼 | 売掛先との関係が良好であること | 売掛先の社内手続き次第 | 費用はかからないが、応じるかは売掛先の判断 |
| ファクタリング | 売掛金（請求書）があること | 会社により異なる（各社の公式表示は[手数料比較](/fees/)） | 手数料がかかる。売掛金の額面より少ない金額を受け取る |
| 日本政策金融公庫 セーフティネット貸付 | 売上の減少などの要件に該当すること | 審査を経て融資が決まる | 返済が必要。当日の支払いに充てる前提では組み立てない |
| 取引金融機関の融資・借換え | 金融機関の審査 | 審査を経て融資が決まる | 返済が必要 |
| 支払猶予・返済条件の変更 | 相手方の合意、または制度の要件 | 合意・許可の時点から | 支払いがなくなるわけではない |

### 日本政策金融公庫のセーフティネット貸付

日本政策金融公庫の「経営環境変化対応資金（セーフティネット貸付）」は、社会的・経済的環境の変化等の外的要因により、一時的に売上の減少等の業況悪化をきたしている方で、中長期的には業況が回復し発展することが見込まれる方が対象です。国民生活事業のページに記載された主な条件は次のとおりです。

- 対象：最近の決算期の売上高が前期または前々期に比べ5%以上減少している方、最近3か月の売上高が前年同期または前々年同期に比べ5%以上減少し今後も減少が見込まれる方、回収条件の長期化または支払条件の短縮化等により取引条件が0.1か月以上悪化している方など
- 融資限度額：7,200万円（中小企業事業は直接貸付7億2千万円）
- 返済期間：運転資金10年以内（うち据置期間3年以内）、設備資金20年以内（うち据置期間3年以内）
- 利率：基準利率（一部の条件に該当する方は特別利率）

審査を経て融資が決まる制度のため、今日・明日の支払いではなく、不足が数か月続く場合の手当てとして今週中に相談を始めておくと、資金が必要な時期に間に合わせやすくなります。

### ファクタリングは売掛金がある場合の選択肢の一つ

ファクタリングは、入金前の売掛金を買い取ってもらい、支払期日より前に資金化する方法です。売掛金がなければ利用できず、手数料の分だけ受け取る金額は額面より少なくなります。

例：売掛金100万円を、手数料率10%でファクタリングした場合（仮定）
- 受取額は90万円、手数料は10万円です（振込手数料などの諸費用は含みません）
- 実際の手数料率は、売掛先の信用力や2社間・3社間の別により各社が見積もります。各社の公式表示の手数料は[手数料比較](/fees/)をご覧ください

不足額が売掛金の一部で足りる場合は、全額ではなく必要な分の請求書だけを資金化すると手数料を抑えられます。当日中の入金を受けるための申込時間や必要書類は[即日ファクタリングガイド](/articles/article-factoring-sokujitsu/)に、即日入金に対応した会社の比較は[即日入金のファクタリング会社](/articles/article-factoring-sokujitsu-osusume/)にまとめています。ファクタリングを継続的な資金繰りの改善に使う場合の考え方は、[ファクタリングで資金繰りを改善する方法](/articles/article-factoring-shikinguri/)をご覧ください。

急いでいる時ほど、契約内容が実質的に貸付にあたる業者や、手数料の説明があいまいな業者に注意が必要です。見分け方は[違法業者の見分け方](/articles/article-factoring-ihou-gyousha/)で説明しています。

## 例：今週の支払いに不足がある会社の初動（仮定）

以下は、優先順位の付け方を示すための仮定の例です。

- 預金残高：250万円
- 売掛金：A社向け150万円（入金予定は来月末）
- 今後2週間の支払い

| 期日 | 支払い | 金額 | 判断 |
|---|---|---|---|
| 3日後 | でんさいの決済（仕入先B社） | 80万円 | 期日を動かせない。残高から確保する |
| 5日後 | 給与 | 120万円 | 期日を動かせない。残高から確保する |
| 7日後 | 源泉所得税・社会保険料 | 60万円 | 納期限前に税務署・年金事務所へ相談する |
| 10日後 | 銀行返済 | 50万円 | 期日前に金融機関へ相談する |
| 14日後 | 事務所家賃 | 30万円 | 期日前に貸主へ相談する |
| 合計 | | 340万円 | 不足額は90万円 |

この例では、でんさいと給与の200万円を残高から先に確保すると、残りは50万円です。税金・社会保険料、銀行返済、家賃の合計140万円に対して90万円が不足します。

1. 今日：税務署・年金事務所・取引金融機関・貸主に、期日前に連絡を入れる
2. 今日〜明日：A社に支払日の前倒しが可能か打診する。難しければ、A社向け売掛金のファクタリングの見積もりを取る（手数料率10%と仮定すると、150万円の売掛金から受け取るのは135万円）
3. 今週中：税金・社会保険料の猶予が認められるか、返済条件の変更に応じてもらえるかを確認し、資金化する額を必要な分に絞る
4. 今週中：不足が来月以降も続く見通しであれば、日本政策金融公庫に相談する

相談や猶予で支払いを先に延ばせる分が大きいほど、ファクタリングで資金化する額を減らせ、手数料の負担も小さくなります。

## よくある質問

**Q: 支払いが間に合わない時、どの支払いを優先すべきですか。**
A: 当サイトでは、期日を動かせず影響が大きい手形・でんさいの決済と給与を最優先とし、税金・社会保険料は猶予制度の申請、借入返済・仕入代金・家賃は期日前の相談で支払日の調整を図る順番を目安としています。個別の事情によって判断は変わるため、税理士や取引金融機関にも相談してください。

**Q: 税金を期限までに払えない場合、まず何をすればよいですか。**
A: 所轄の税務署の徴収担当に電話で相談します。国税庁のFAQでは、換価の猶予は納期限から6か月以内の申請が必要で、延滞税は納期限の翌日から発生するため、できるだけ早い申請を勧めています。納期限を過ぎてから申請すると、納期限の翌日から申請日の前日までの延滞税は軽減されないため、納期限までに申請すると負担を抑えられます。

**Q: 赤字でなくても税金の猶予は受けられますか。**
A: 国税庁のFAQでは、黒字であっても要件を満たせば猶予を受けられるとしています。判断の基準は、手元資金から当面の資金繰りに必要な額を差し引いた金額が、納付すべき国税の額に満たないかどうかです。

**Q: ファクタリングを使えば今日中に支払いに間に合いますか。**
A: 当日中の入金に対応している会社もありますが、申込の時間帯、必要書類の準備状況、審査の結果によって入金日は変わります。また、売掛金がなければ利用できません。当日中の入金の条件は[即日ファクタリングガイド](/articles/article-factoring-sokujitsu/)をご覧ください。

## まとめ

支払いが間に合わないと分かった日は、今後30日の支払いと入金を期日順に一覧にし、期日を動かせない支払いと、相談・申請で動かせる支払いに分けることから始めます。手形・でんさいの決済は、6か月以内に2回の不渡・支払不能で取引停止処分となるため最優先で残高を確保し、給与は労働基準法24条に沿って期日どおりに支払う前提で組み立てます。

税金・社会保険料は、国税庁・日本年金機構の猶予制度を納期限の前に申請することで、延滞税・延滞金の負担を抑えながら分割で納付できる可能性があります。借入返済・仕入代金・家賃は、期日の前に相手方へ相談します。そのうえで残る不足額に対して、売掛先への前倒しの依頼、売掛金がある場合のファクタリング、日本政策金融公庫のセーフティネット貸付を、資金が届くまでの時間と費用を比べて選んでください。

本記事の制度の内容は、2026年10月31日時点で各機関の公式ページを確認したものです。申請の前に、所轄の税務署・年金事務所・各機関の公式サイトにて最新の情報をご確認ください。
