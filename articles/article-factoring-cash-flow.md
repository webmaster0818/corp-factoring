# ファクタリングのキャッシュフロー計算書での処理｜営業・財務・投資 CF のどこに記載するか

**対策KW:** ファクタリング キャッシュフロー計算書
**月間検索Vol:** 500〜1,000
**想定文字数:** 4,000字
**ステータス:** 下書き

---

ファクタリングを利用した際に、キャッシュフロー計算書（CF計算書）上のどの区分に記載するかは、経理担当者が判断に迷いやすい論点です。原則として「営業活動によるキャッシュフロー」に区分されますが、ケースによっては財務活動 CF として処理することもあります。本記事では、その詳細を解説します。

---

## ファクタリングの CF 区分: 原則は「営業 CF」

**基本的な考え方:** ファクタリングによる入金は、売掛金の回収の前倒しにあたるため、営業活動 CF に区分します。

**根拠:**
- 売掛金は本業から発生する資産
- 売掛金の現金化は、本業の収入の前倒しにあたる
- CF 計算書の原則: 売掛金の増減は営業 CF に区分する

## 間接法での記載方法

**間接法 CF 計算書:**
```
営業活動によるキャッシュフロー
  税引前当期純利益               XXX
  売上債権売却損(調整不要)        +5万
  売掛金の減少                  +100万
  ...
```

間接法で記載する際の主なポイントは、次のとおりです。
- 売掛金の減少は、営業 CF にプラスで計上する
- 売上債権売却損は「非資金費用」ではないため、調整は不要
- 結果として、営業 CF は +95 万円（実際の入金額と一致）

## 直接法での記載方法

**直接法 CF 計算書:**
```
営業活動によるキャッシュフロー
  営業収入(売掛金回収を含む)      +95万
  営業支出                       -XXX
  ...
```

直接法では、次の点に留意して記載します。
- 売掛金の売却による入金 95 万円を「営業収入」として計上する
- 売却損 5 万円の計上は不要（差し引き後の入金額が CF となる）

## 継続契約・大規模利用時の処理

**継続契約型のファクタリング:**
- 売掛金を売却するたびに、営業 CF として計上する
- 月次で集計するのが一般的

**大規模に利用する場合（年商の 5% 以上）:**
- CF 計算書の注記に、重要なファクタリング取引として記載することを推奨
- 投資家・銀行への説明資料として活用する

**特殊なケース（ノンリコースとリコース）:**
- ノンリコース（償還義務なし）: 通常の営業 CF として処理する
- リコース（償還義務あり）: 借入金に近い性質を持つため、財務 CF として処理する見解もある

## CF 計算書全体への影響

**営業 CF の変動:**
- 売掛金の減少は、営業 CF のプラスとなる
- ファクタリングを多用すると、営業 CF が実態より大きく見える点に注意が必要

**投資家・銀行の視点:**
- 営業 CF の質を判断するため、ファクタリングの利用比率は注目される
- 過度な依存は警戒される（売掛金が継続的に手元にない状態）

## よくある質問

**Q: ファクタリングは営業 CF と財務 CF のどちらに区分しますか？**
A: 原則として営業 CF に区分します。売掛金の前倒しでの回収という性格上、本業のキャッシュの動きとして処理します。

**Q: ノンリコースとリコースで CF の区分は変わりますか？**
A: 通常はどちらも営業 CF に区分します。ただし、リコース（償還義務あり）の取引を実質的に借入金として処理する場合は、財務 CF とする見解もあります。

**Q: 間接法と直接法のどちらが推奨されますか？**
A: 中小企業では間接法が一般的です。大企業や上場企業では、直接法を併用する場合もあります。

**Q: CF 計算書の注記にファクタリングを記載すべきですか？**
A: 重要性の高い取引（年商の 5% 以上等）は、注記に記載することを推奨します。透明性を確保するためです。

**Q: ファクタリングの多用により営業 CF が大きく見える場合の対策は？**
A: 売掛金回転日数を併記し、ファクタリングを利用しなかった場合の本業の CF も推計できるようにしてください。

**Q: 税理士と意見が分かれる場合は、どのように対応すればよいですか？**
A: 重要性の判断は個別の状況によって異なるため、税理士・公認会計士と相談のうえ、社内のルールを決定してください。
