# ファクタリングのキャッシュフロー計算書・財務諸表での扱い｜入金は営業CF・売掛金はオフバランス【会計基準で確認】

**対策KW:** ファクタリング キャッシュフロー計算書
**メタdescription:** ファクタリングの入金はキャッシュフロー計算書の「営業活動によるキャッシュ・フロー」に記載（移管指針第6号 第7項・第31項）。貸借対照表は金融商品会計基準 第9項の要件を満たせば売掛金をオフバランスにし、償還請求権は時価で負債計上。要件を満たさなければ金融取引。出典つき（2026年10月27日確認）。

## 結論：ファクタリングは財務諸表でどう扱うか（早見表）

ファクタリング（売掛債権の売却）の入金は、キャッシュフロー計算書では**「営業活動によるキャッシュ・フロー」**に記載します。貸借対照表では、金融商品会計基準の**消滅の認識要件**を満たせば売掛金を消滅させ（オフバランス）、売却額と帳簿価額の差額を損益に計上します。償還請求権（リコース）が付いていても、要件を満たせば売却として処理し、償還義務は**時価で負債に計上**します。買戻す権利・義務を実質的に持つなど要件を満たさない場合は、売買ではなく**金融取引**として処理します。

| 財務諸表 | 扱い | 根拠（2026年10月27日確認） |
|---|---|---|
| キャッシュフロー計算書 | 営業債権のファクタリングによる収入は「営業活動によるキャッシュ・フロー」 | 移管指針第6号「連結財務諸表等におけるキャッシュ・フロー計算書の作成に関する実務指針」第7項(2)・第31項 |
| キャッシュフロー計算書（金額） | 売却損を差し引いた手取額で示す方法と、債権の総額で収入があったとみなす方法のどちらも可（受取手形の割引等について） | 同 実務指針の設例の注記 |
| 貸借対照表（売掛金） | 支配が移転したとき（第9項の3要件をすべて満たすとき）に消滅を認識＝オフバランス | 企業会計基準第10号「金融商品に関する会計基準」第8項・第9項 |
| 損益計算書 | 帳簿価額と受取額との差額を当期の損益（売却損）として処理 | 同 第11項 |
| 償還請求権（リコース）付き | 消滅に伴って新たに生じた負債は時価で計上（手形の割引では「保証債務」として時価で計上） | 同 第13項・移管指針第9号「金融商品会計に関する実務指針」第136項・設例2 |
| 要件を満たさない場合 | 買戻す権利・義務を実質的に持つ取引は、売買ではなく金融取引として処理 | 金融商品に関する会計基準 第58項(3) |
| 中小企業の会計 | 金融機関等による金銭債権の買取りは「金銭債権の譲渡」に該当 | 「中小企業の会計に関する指針」（令和7年9月19日修正）第14項 |
| 消費税 | 金銭債権の譲渡は非課税（売掛金を売っても消費税はかからない） | 国税庁タックスアンサー No.6201 |

ここでの「ファクタリング」は、売掛債権をファクタリング会社に売却する買取型の取引を指します。個々の契約が売却に当たるか（第9項の要件を満たすか）は契約条項しだいのため、決算での処理は顧問税理士・公認会計士に契約書を見せて確認してください。

## キャッシュフロー計算書：入金は「営業活動によるキャッシュ・フロー」

キャッシュフロー計算書の表示区分は、企業会計基準委員会（ASBJ）の移管指針第6号「連結財務諸表等におけるキャッシュ・フロー計算書の作成に関する実務指針」（2026年7月改正）が定めています。

- **第7項(2)**：営業活動に係る債権・債務から生じるキャッシュ・フローには、「商品及び役務の販売により取得した手形の割引による収入、営業債権のファクタリング等による収入も含まれる」
- **第31項**：手形の割引のように受取手形を約定期日より早く回収する行為には「財務活動としての性格を有するという意見もある」としたうえで、財務活動に記載すると営業活動によるキャッシュ・フローの情報が明確に表示されず、企業間の比較可能性を損なうおそれがあるため、営業債権・債務から生じるキャッシュ・フローは営業活動の区分に記載するとし、「同様に、営業債権のファクタリングや各種の営業債権の流動化に伴うキャッシュ・フローは、『営業活動によるキャッシュ・フロー』の区分に記載することになる」

つまり、売掛金を売却して得た入金は、借入れに似た資金調達であっても「財務活動」ではなく「営業活動」に記載します。

### 間接法での記載例

100万円の売掛金を95万円で売却した（売却損5万円）場合の、売却に関係する部分だけを示します。

```
営業活動によるキャッシュ・フロー
  税引前当期純利益            ×××（売却損5万円を差し引いた後の利益）
  売上債権の減少額           +100万
  （売却損5万円は加減しない）
  → この取引の営業CFへの影響は +95万（実際の入金額）
```

- 売却損5万円は、すでに税引前当期純利益に含まれて利益を減らしています。受取額が額面より5万円少ないという現金の動きそのものなので、利益に足し戻す調整はしません
- その結果、この取引による営業CFの増加は、実際の入金額95万円と一致します

### 直接法での記載例

```
営業活動によるキャッシュ・フロー
  営業収入（売掛金の回収・売却を含む）   +95万（手取額で示す場合）
  営業支出                           ×××
```

移管指針第6号の設例の注記は、受取手形の割引等による収入について「①手形売却損控除後の手取額による方法と②手形金額等の総額による収入があったとみなす方法があるが、いずれの方法によることもできる」としています。上の例では、手取額で示す方法なら営業収入は95万円です。総額で示す方法をとる場合の売却損の示し方は、顧問の会計専門家と決めてください。

### キャッシュフロー計算書を作る必要があるか

会社法で各事業年度に作る計算書類は、貸借対照表・損益計算書・株主資本等変動計算書・個別注記表で（会社法第435条第2項・会社計算規則第59条第1項）、キャッシュフロー計算書は含まれていません。銀行への提出や社内管理のために任意で作る場合も、表示区分の考え方は上の実務指針が参考になります。

## 貸借対照表：売掛金はオフバランス（消滅の認識要件を満たす場合）

売掛金を売却したときに売掛金を貸借対照表から外せるかどうかは、企業会計基準第10号「金融商品に関する会計基準」（最終改正 2026年6月2日）で決まります。

- **第8項**：金融資産の契約上の権利に対する支配が他に移転したときは、その金融資産の消滅を認識する
- **第9項**：支配が移転するのは、次の3つをすべて満たした場合
  1. 譲渡された金融資産に対する譲受人の契約上の権利が、譲渡人とその債権者から法的に保全されていること
  2. 譲受人が、譲渡された金融資産の契約上の権利を直接または間接に通常の方法で享受できること
  3. 譲渡人が、譲渡した金融資産を満期日前に買戻す権利と義務を実質的に持っていないこと
- **第11項**：消滅を認識したときは、帳簿価額と対価としての受払額との差額を当期の損益として処理する

上の例（100万円の売掛金を95万円で売却）で要件を満たす場合、売掛金100万円が減り、現金95万円が増え、差額5万円を売却損（勘定科目は「売上債権売却損」など）として計上します。売掛金と同時に資産が減るため、借入れで資金を得た場合と違って、負債は増えません。

中小企業向けの「中小企業の会計に関する指針」（日本公認会計士協会・日本税理士会連合会・日本商工会議所・企業会計基準委員会、令和7年9月19日修正）も、第14項で「手形の割引又は裏書及び金融機関等による金銭債権の買取りは、金銭債権の譲渡に該当する」としています。

## 償還請求権（リコース）の有無で会計処理はどう変わるか

償還請求権とは、売掛先が支払わなかったときに、ファクタリング会社が利用者（売掛債権を売った側）に支払いを求める権利です。償還請求権がない契約を「ノンリコース」、ある契約を「リコース」といいます。

| 契約 | 貸借対照表 | 根拠 |
|---|---|---|
| ノンリコース（償還請求権なし） | 第9項の要件を満たせば、売掛金を消滅させ、差額を売却損益に | 金融商品に関する会計基準 第8項・第9項・第11項 |
| リコース付きでも第9項の要件を満たす | 売掛金は消滅させる。償還義務（リコース義務）は新たに生じた負債として時価で計上し、その分を差し引いて売却損益を計算 | 同 第13項、金融商品会計に関する実務指針 設例2（リコース義務を「新たな負債」として時価で計上する例）、第136項（手形の割引で生じる二次的責任を保証債務として時価で計上） |
| 買戻す権利・義務を実質的に持つなど、第9項の要件を満たさない | 売却として扱わず、金融取引（売掛金を担保にした借入れと同様の取引）として処理 | 同 第58項(3) |

金融商品に関する会計基準は、譲渡後も譲渡人がリコース権（遡求権）や買戻特約などを持つ「条件付きの譲渡」について、資産を財務的な要素に分けて、支配が移った要素だけを消滅させる考え方（財務構成要素アプローチ）を採っています（第57項・第58項）。そのため、**償還請求権があるというだけでは売却処理ができなくなるわけではなく**、第9項の3要件を満たすかどうかで判断し、償還義務は負債として別に計上します。

なお、売却ではなく金融取引として処理した場合の入金をキャッシュフロー計算書のどの区分に記載するかについて、移管指針第6号には「ファクタリング」としての個別の記載がありません。この場合は顧問の会計専門家に確認してください。

### 注記

- 会社計算規則第103条第5号は、保証債務・手形遡求債務などの債務（負債の部に計上したものを除く）があるときは、その内容と金額を貸借対照表等に関する注記とするよう定めています
- 中小企業の会計に関する指針 第15項(4) は、受取手形割引額・受取手形譲渡額を、注記が求められない場合でも注記することが望ましいとしています

## 消費税：売掛金の売却は非課税

国税庁タックスアンサー No.6201「非課税となる取引」は、非課税となる有価証券等の譲渡の例として「金銭債権などの譲渡」を挙げています（令和8年4月1日現在法令等・2026年10月27日確認）。また No.6405「課税売上割合の計算方法」は、課税売上割合を計算するとき、資産の譲渡等の対価として取得した売掛金などの金銭債権の譲渡は総売上高に含めないとしています。ファクタリングの手数料（売却損）の法人税・消費税上の扱いは、契約の内容によって異なることがあるため、顧問税理士に確認してください。

## キャッシュフロー計算書の数字の読み方（注意点）

- ファクタリングで売掛金を前倒しで回収した期は、売上債権の減少額の分だけ営業活動によるキャッシュ・フローが増えます。一方で、売却した売掛金は本来の支払期日に入金されないため、その分は翌期以降の回収額に含まれません
- 売却損（手数料）の分、受取額は額面より少なくなります。継続して利用する場合は、売却損の合計と、ファクタリングを使わなかった場合の資金繰りを比べて判断してください

## よくある質問

**Q: ファクタリングはキャッシュフロー計算書のどの区分に記載しますか？**
A: 「営業活動によるキャッシュ・フロー」です。移管指針第6号「連結財務諸表等におけるキャッシュ・フロー計算書の作成に関する実務指針」第7項(2)が「営業債権のファクタリング等による収入」を営業活動の区分に含めると定め、第31項でも営業債権のファクタリングに伴うキャッシュ・フローは営業活動の区分に記載するとしています（2026年10月27日確認）。

**Q: ファクタリングを使うと、売掛金は貸借対照表から消えますか（オフバランスになりますか）？**
A: 金融商品に関する会計基準 第9項の3要件（譲受人の権利が法的に保全されている・譲受人が通常の方法で権利を享受できる・譲渡人が満期日前に買戻す権利と義務を実質的に持たない）をすべて満たせば、売掛金の消滅を認識し、帳簿価額と受取額の差額を売却損益として処理します（第8項・第9項・第11項）。満たさない場合は金融取引として処理します（第58項(3)）。

**Q: 償還請求権（リコース）付きのファクタリングは借入金になりますか？**
A: 償還請求権があるだけでは決まりません。第9項の要件を満たせば売却として売掛金を消滅させ、償還義務は新たに生じた負債として時価で計上します（金融商品に関する会計基準 第13項、金融商品会計に関する実務指針 設例2・第136項）。買戻す権利と義務を実質的に持つなど要件を満たさない場合は、売買ではなく金融取引として処理します（同基準 第58項(3)）。

**Q: 間接法で売却損（手数料）は足し戻しますか？**
A: 足し戻しません。売却損は額面より少ない金額しか受け取らなかったことを表しており、利益を減らした分だけ実際の入金も少ないためです。売上債権の減少額（額面）を加算すると、この取引の営業CFへの影響は実際の入金額と一致します。

**Q: 直接法では手取額と総額のどちらで記載しますか？**
A: どちらでも構いません。移管指針第6号の設例の注記は、受取手形の割引等による収入について、手形売却損を控除した手取額で示す方法と、手形金額等の総額で収入があったとみなす方法のいずれによることもできるとしています。

**Q: 中小企業でもキャッシュフロー計算書を作る必要がありますか？**
A: 会社法で作る計算書類（貸借対照表・損益計算書・株主資本等変動計算書・個別注記表）にキャッシュフロー計算書は含まれていません（会社法第435条第2項・会社計算規則第59条第1項）。任意で作る場合も、ファクタリングの入金は営業活動の区分に記載します。

**Q: 売掛金をファクタリングで売ると消費税はかかりますか？**
A: 金銭債権の譲渡は消費税の非課税取引です（国税庁タックスアンサー No.6201）。課税売上割合の計算では、資産の譲渡等の対価として取得した売掛金などの譲渡は総売上高に含めません（同 No.6405）。
