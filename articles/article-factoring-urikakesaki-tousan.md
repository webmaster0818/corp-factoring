# ファクタリング後に売掛先が倒産した場合のリスクと対処法を解説【2026年】

**対策KW:** ファクタリング 売掛先 倒産, ノンリコース ファクタリング
**月間検索Vol:** 500〜800
**想定文字数:** 5,000字
**ステータス:** 下書き

---

ファクタリングの利用後に売掛先が倒産した場合にどうなるか、返金を求められないかといった点は、ファクタリングの利用者が最も気にする点の一つです。この記事では、その扱いを解説します。

---

## 売掛先の倒産時の扱いは、契約の種類によって異なる

### ノンリコース（買取保証型）

**最も一般的な契約形式です。** 売掛先が倒産しても、申込者に支払いの義務は生じません。

```
【ノンリコースの場合】
ファクタリング会社が倒産リスクを負担
→ 申込者への請求なし
→ 申込者の損失なし（手数料分は発生済み）
```

ファクタリング会社は、売掛先の倒産リスクを評価して手数料を設定しています。リスクが高い売掛先ほど手数料が高くなるのは、このためです。

### リコース（買戻し義務あり）

一部のファクタリング契約では、**売掛先が倒産した場合に、申込者が買い戻す義務（リコース）**が設定されています。

```
【リコースの場合】
売掛先が倒産
→ ファクタリング会社が申込者に買戻しを請求
→ 申込者は、受取済みの金額を返還する必要がある
```

なお、リコース型はファクタリングではなく、担保付きの融資に近い性質を持ちます。契約前に必ず確認してください。

---

## 日本のファクタリングは原則としてノンリコース

[2社間・3社間ファクタリング](/articles/article-factoring-2sha-3sha/)を含め、日本の主要なファクタリング会社の大半は、**ノンリコース型**です。

| 確認すべき契約書の文言 | ノンリコース | リコース |
|-------------------|-----------|--------|
| 「買取保証」「債権の譲渡」 | ○ | — |
| 「買戻し義務」「弁済義務」 | — | △ 注意が必要 |
| 「リコース」の明記 | — | × 避けるべき |

## 売掛先が倒産した場合の実際の流れ

### ノンリコース型の場合

```
1. ファクタリング会社が倒産を把握
2. 破産管財人に対し債権者として届出
3. ファクタリング会社が損失を被る
4. 申込者への影響：なし（手数料は既払い）
```

### リコース型の場合

```
1. 売掛先が倒産
2. ファクタリング会社が申込者に連絡
3. 申込者は受取済み額（手数料差引後）を返還
4. 申込者が破産管財人に対して直接請求を行う
```

## 売掛先の倒産リスクを事前に下げる方法

### 方法1：複数の売掛先に分散する

一社の売掛先への依存度が高いと、その会社が倒産した場合のリスクが大きくなります。

```
【リスク分散の例】
× A社1社への売掛金1,000万円 → A社の倒産で大きな影響
○ A社300万円 + B社400万円 + C社300万円 → 分散によりリスクを軽減
```

### 方法2：売掛先の財務状況を確認する

帝国データバンク・東京商工リサーチの評点を定期的に確認することで、売掛先の信用リスクを把握できます。

**無料でできる確認方法：**
- 官報の破産情報を確認する
- 売掛先の決算公告（大会社は義務）を確認する
- 報道で経営状況を把握する

### 方法3：支払期日の短縮の交渉

支払いサイトが長いほど、倒産のリスクは高まります。可能な範囲で、前払いや短期での支払いを交渉してください。

### 方法4：取引開始時の信用調査

新規の取引先とは少額から取引を始め、入金の実績を確認してから取引を拡大することをおすすめします。

## 売掛先の倒産が懸念される場合の早期の対応

売掛先の倒産が懸念される場合は、**早めにファクタリングで現金化**することも一つの方法です。

ただし、**倒産を知りながら、架空の売掛金でファクタリングを行う行為は、詐欺罪**にあたります。

```
【適法な早期対応】
・支払期日前に、合法的なファクタリングで現金化する
・契約に問題がない（倒産の事実を隠していない）

【違法な行為】
・倒産が近いことを知りながら、虚偽の説明でファクタリングを利用する
・架空の請求書でファクタリングを申し込む
```

[ファクタリング詐欺・違法業者](/articles/article-factoring-sagi/)についての注意点も、あわせてご確認ください。

---

## 売掛先の倒産後の財産の回収（破産手続き）

ファクタリングの後に売掛先が倒産した場合（ノンリコース）：
- 申込者に返還の義務はない
- ファクタリング会社が、破産財団から配当を受ける立場になる

ファクタリングの前に売掛先が倒産した場合（売掛金がまだ手元にある）：
- 申込者が破産債権者として届け出る
- 配当は破産財団による（多くの場合、回収率は低い）

---

## まとめ

ノンリコース型のファクタリングであれば、売掛先が倒産しても、申込者に返済の義務は生じません。これは、ファクタリングの大きなメリットの一つです。[資金繰り改善](/articles/article-factoring-shikinguri/)の手段として活用しながら、売掛先の分散・信用管理も並行して行ってください。契約前に、[ファクタリング会社の比較](/articles/article-factoring-hikaku/)を参考に、ノンリコース型であるかを必ず確認してください。

## よくある質問（FAQ）

**Q: ファクタリングの利用後に売掛先が倒産した場合、お金を返さなければなりませんか？**
A: ノンリコース型（買取保証型）であれば、返還の義務はありません。日本の主要なファクタリング会社の大半は、ノンリコース型です。

**Q: ノンリコースとリコースの違いはどこで確認できますか？**
A: 契約書の「買戻し義務」「リコース」「弁済義務」などの文言を確認してください。不明な場合は、ファクタリング会社に直接確認してください。

**Q: 売掛先が倒産しそうな場合、ファクタリングを利用して損失を回避できますか？**
A: 適法な範囲であれば可能です。ただし、倒産の事実を隠してファクタリングを利用することは、詐欺にあたります。

**Q: 売掛先の倒産リスクが高いと、手数料は上がりますか？**
A: 上がります。ファクタリング会社は売掛先の信用力を審査し、リスクが高いほど高い手数料を設定します。

**Q: ファクタリングに利用した売掛金が、後から不正であると判明した場合はどうなりますか？**
A: 架空の売掛金や詐欺的なファクタリングは、民事・刑事の両面で責任を問われます。必ず、実在する取引の売掛金のみを利用してください。
