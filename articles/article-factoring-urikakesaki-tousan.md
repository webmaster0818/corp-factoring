# ファクタリング後に売掛先が倒産したら？リスクと対処法を徹底解説【2026年】

「ファクタリングを使った後、売掛先が倒産したらどうなる？」「お金を返せ、と言われないか心配」——売掛先の倒産リスクはファクタリング利用者が最も気にするポイントの一つです。正確に理解しておきましょう。

---

## 売掛先倒産時の扱いは契約タイプで異なる

### ノンリコース（買取保証型）

**最も一般的な契約形式。** 売掛先が倒産しても申込者に支払い義務は生じません。

```
【ノンリコースの場合】
ファクタリング会社が倒産リスクを負担
→ 申込者への請求なし
→ 申込者の損失なし（手数料分は発生済み）
```

**ポイント：** ファクタリング会社は売掛先の倒産リスクを評価して手数料を設定しています。リスクが高い売掛先ほど手数料が高くなる理由がここにあります。

### リコース（買戻し義務あり）

一部のファクタリング契約では、**売掛先が倒産した場合に申込者が買い戻す義務（リコース）**が設定されています。

```
【リコースの場合】
売掛先が倒産
→ ファクタリング会社が申込者に買戻しを請求
→ 申込者は受取済みの金額を返還する必要あり
```

**注意：** リコース型はファクタリングではなく「担保付き融資」に近い性質です。契約前に必ず確認してください。

## 日本のファクタリングは原則ノンリコース

[2社間・3社間ファクタリング](/articles/article-factoring-2sha-3sha/)を含め、日本の主要なファクタリング会社のほとんどは**ノンリコース型**です。

| 確認すべき契約書の文言 | ノンリコース | リコース |
|-------------------|-----------|--------|
| 「買取保証」「債権の譲渡」 | ○ | — |
| 「買戻し義務」「弁済義務」 | — | △ 要注意 |
| 「リコース」の明記 | — | × 避けるべき |

## 売掛先が倒産した場合の実際の流れ

### ノンリコース型の場合

```
1. ファクタリング会社が倒産を把握
2. 破産管財人に対し債権者として届出
3. ファクタリング会社が損失を被る
4. 申込者への影響：なし（手数料は既払い）
```

### リコース型の場合

```
1. 売掛先が倒産
2. ファクタリング会社が申込者に連絡
3. 申込者は受取済み額（手数料差引後）を返還
4. 申込者が破産管財人に対して直接請求を行う
```

## 売掛先の倒産リスクを事前に下げる方法

### 方法1：複数の売掛先に分散する

一社の売掛先への依存度が高いと、その会社が倒産したときのリスクが大きくなります。

```
【リスク分散の例】
× A社1社への売掛金1,000万円 → A社倒産で大打撃
○ A社300万円 + B社400万円 + C社300万円 → 分散でリスク軽減
```

### 方法2：売掛先の財務状況をチェックする

帝国データバンク・東京商工リサーチのスコアを定期確認することで、売掛先の信用リスクを把握できます。

**無料でできるチェック方法：**
- 官報の破産情報を確認
- 売掛先の決算公告（大会社は義務）を確認
- ニュースで経営状況をウォッチ

### 方法3：支払期日を短縮する交渉

支払いサイトが長いほど倒産リスクが高まります。可能な範囲で前払いや短期払いの交渉を行いましょう。

### 方法4：取引開始時に信用調査を行う

新規の取引先とは少額から始め、入金実績を確認してから取引を拡大することをお勧めします。

## 売掛先が「倒産しそう」な場合の早期対応

ファクタリングを使う前に売掛先が倒産しそうな場合は、**早めにファクタリングを使って現金化**することも一つの方法です。

ただし、**倒産を知りながら架空の売掛金でファクタリングを行う行為は詐欺罪**に当たります。

```
【適法な早期対応】
・支払期日前に合法的なファクタリングで現金化
・契約に問題なし（倒産の事実を隠蔽していない）

【違法行為】
・倒産間近を知りながら虚偽説明でファクタリング
・架空の請求書でファクタリング申込
```

[ファクタリング詐欺・違法業者](/articles/article-factoring-sagi/)についての注意点も確認してください。

## 売掛先倒産後の財産回収（破産手続き）

ファクタリング後に売掛先が倒産した場合（ノンリコース）：
- 申込者は返還義務なし
- ファクタリング会社が破産財団から配当を受ける立場になる

ファクタリング前に売掛先が倒産した場合（まだ売掛金が手元にある）：
- 申込者は破産債権者として届出
- 配当は破産財団次第（多くの場合、回収率は低い）

## まとめ

ノンリコース型のファクタリングであれば、売掛先が倒産しても申込者に返済義務は生じません。これがファクタリングの大きなメリットの一つです。[資金繰り改善](/articles/article-factoring-shikinguri/)の手段として活用しながら、売掛先の分散・信用管理も並行して行いましょう。契約前に[ファクタリング会社の比較](/articles/article-factoring-hikaku/)でノンリコース型かどうかを必ず確認してください。

## よくある質問（FAQ）

**Q: ファクタリング後に売掛先が倒産したら、お金を返さなければなりませんか？**
A: ノンリコース型（買取保証型）であれば返還義務はありません。日本の主要なファクタリング会社はほとんどがノンリコース型です。

**Q: ノンリコースとリコースの違いはどこで確認できますか？**
A: 契約書の「買戻し義務」「リコース」「弁済義務」などの文言を確認してください。不明な場合はファクタリング会社に直接確認しましょう。

**Q: 売掛先が倒産しそうな場合、ファクタリングを使って損を回避できますか？**
A: 適法な範囲であれば可能です。ただし倒産の事実を隠してファクタリングを使うことは詐欺に当たります。

**Q: 売掛先の倒産リスクが高いと手数料が上がりますか？**
A: はい。ファクタリング会社は売掛先の信用力を審査し、リスクが高いほど高い手数料を設定します。

**Q: ファクタリングで使った売掛金が後から不正だった場合はどうなりますか？**
A: 架空売掛や詐欺的なファクタリングは民事・刑事両面で責任を問われます。必ず実在する取引の売掛金のみ使用してください。
