ファクタリングを利用した際の会計上の仕訳方法や、使用する勘定科目は、経理担当者・経営者が判断に迷いやすい点です。この記事では、具体的な数字を用いて解説します。

---

## ファクタリングの勘定科目の基本

### 使用する主な勘定科目

| 場面 | 使用する勘定科目 | 分類 |
|-----|-------------|-----|
| 売掛金を計上するとき | **売掛金** | 資産 |
| 手数料を処理するとき | **売上債権売却損** または **支払手数料** | 費用 |
| 入金されたとき | **普通預金** または **現金** | 資産 |
| 3社間で売掛先が直接振り込む場合 | **普通預金**（ファクタリング会社の口座へ） | — |

### 「売上債権売却損」と「支払手数料」のどちらを使うか

| 勘定科目 | 適した場面 | 税務上の扱い |
|---------|----------|------------|
| **売上債権売却損** | ファクタリング専用の費用として明確にしたい | 損金算入可 |
| **支払手数料** | 簡潔に経費として処理したい | 損金算入可 |

いずれを使っても、税務上の効果は変わりません。同じ科目を継続して使うことが重要です。

## 2社間ファクタリングの仕訳パターン

### 前提条件

- 売掛金：100万円（A社宛）
- ファクタリング手数料：8%（8万円）
- 入金額：92万円（100万円 - 8万円）
- 支払期日：翌月末

### 仕訳①：売掛金が発生したとき

```
（借方）売掛金 1,000,000円
       ／（貸方）売上高 1,000,000円
```

### 仕訳②：ファクタリング会社に譲渡したとき（資金受取時）

```
（借方）普通預金      920,000円
（借方）売上債権売却損  80,000円
       ／（貸方）売掛金 1,000,000円
```

### 仕訳③：売掛先からファクタリング会社に入金があったとき（2社間）

2社間ファクタリングでは、**売掛先は利用者に入金**します。その後、利用者がファクタリング会社に送金します。

```
【売掛先からの入金時】
（借方）普通預金 1,000,000円
       ／（貸方）預り金 1,000,000円

【ファクタリング会社への送金時】
（借方）預り金 1,000,000円
       ／（貸方）普通預金 1,000,000円
```

**ポイント：** 売掛先から入金された代金は、すでにファクタリング会社に帰属するものです。「預り金」として処理し、速やかに送金してください。

## 3社間ファクタリングの仕訳パターン

### 前提条件（同じ条件で3社間の場合）

- 売掛金：100万円
- 手数料：3%（3万円）
- 入金額：97万円

### 仕訳①：売掛金が発生したとき

```
（借方）売掛金 1,000,000円
       ／（貸方）売上高 1,000,000円
```

### 仕訳②：ファクタリング会社に譲渡・資金受取時

```
（借方）普通預金      970,000円
（借方）売上債権売却損  30,000円
       ／（貸方）売掛金 1,000,000円
```

### 3社間の特徴

3社間では[売掛先がファクタリング会社に直接入金](/articles/article-factoring-2sha-3sha/)するため、上記の「預り金」の処理は不要です。仕訳は2回で完結します。

## 買取保証型（ノンリコース）の仕訳

[ノンリコース（売掛先の倒産リスクをファクタリング会社が負う）](/articles/article-factoring-urikakesaki-tousan/)の場合、追加の仕訳は基本的に不要です。売掛先が倒産しても申込者への請求はありません。

**リコース（買戻し義務あり）の場合：**

売掛先が倒産し、買戻しを求められた場合の仕訳は以下のとおりです。
```
（借方）売掛金 1,000,000円
       ／（貸方）普通預金 920,000円（受取済の金額）
            （貸方）未払金    80,000円（手数料分）
```

## 消費税の処理

### ファクタリング取引と消費税

| 処理 | 消費税区分 |
|-----|----------|
| 売掛金の譲渡（金融取引） | **非課税**（課税売上にならない） |
| 手数料 | **課税仕入れ**（仕入税額控除の対象） |

**注意：** 消費税の課税事業者は、ファクタリングにより非課税売上が増えると、「課税売上割合」が下がる可能性があります。[個人事業主の確定申告での注意点](/articles/article-factoring-kojin-kakutei/)もあわせてご確認ください。

## よくある仕訳の誤りと正しい処理

### 誤り1：売掛金を入金額で計上してしまう

```
× 誤り
（借方）普通預金 920,000円
       ／（貸方）売上高 920,000円（手数料分が欠落）

○ 正しい
（借方）普通預金      920,000円
（借方）売上債権売却損  80,000円
       ／（貸方）売掛金 1,000,000円
```

### 誤り2：2社間で売掛先からの入金を売上として計上する

```
× 誤り
売掛先入金時：（借方）普通預金 1,000,000 ／（貸方）売上高 1,000,000
（売掛金がすでに消えているのに売上が二重計上される）

○ 正しい処理 → 預り金として計上し、ファクタリング会社に送金
```

## まとめ

ファクタリングの仕訳で最も重要なのは、「売掛金を元の金額で消去し、手数料を費用として計上する」という原則です。2社間では、売掛先からの入金を「預り金」として処理することにも注意してください。[ファクタリングの税金・印紙税](/articles/article-factoring-inshizei/)もあわせてご確認ください。

## よくある質問（FAQ）

**Q: ファクタリングの勘定科目「売上債権売却損」は標準科目ですか？**
A: 法定の標準科目ではありませんが、多くの会計ソフトで科目を追加できます。「支払手数料」を使う場合は、補助科目で「ファクタリング手数料」と区別すると管理しやすくなります。

**Q: 手数料を「雑費」で処理してもよいですか？**
A: 税務上は問題ありませんが、金額が大きい場合や継続して利用する場合は、専用の勘定科目を使うことをおすすめします。

**Q: 2社間で売掛先からの入金が遅れた場合、仕訳はどうなりますか？**
A: 入金が遅れた場合も仕訳の方針は変わりません。ただし、ファクタリング会社への送金期日を守ることが重要です。

**Q: 確定申告（個人事業主）の場合、仕訳の考え方は法人と違いますか？**
A: 基本的な仕訳の考え方は同じです。青色申告の場合は複式簿記で、白色申告の場合は収支の記録として処理します。

**Q: ファクタリングを複数回使った場合、まとめて計上できますか？**
A: 各取引を個別に仕訳することが原則です。ただし、同月内の複数の取引を月次でまとめ、補助科目で管理する方法もあります。
