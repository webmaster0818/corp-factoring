# 資金繰り表の作り方｜日本政策金融公庫の様式で作る手順と税金の支払月

**対策KW:** 資金繰り表 作り方
**メタdescription:** 資金繰り表は「前月繰越金＋収入−支出」を月ごとに積み上げる表で、日本政策金融公庫が様式と記入例を公開しています。公庫の様式の構成と手順①〜⑦、個人事業主が見落としやすい予定納税・確定申告・消費税の納期限を公式の日付で整理しました。
**想定文字数:** 6,000字
**ステータス:** 下書き

---

資金繰り表は、月ごとに「前月繰越金＋収入−支出」を積み上げて翌月繰越金を出し、どの月にお金が足りなくなるかを先に見つけるための表で、日本政策金融公庫（国民生活事業）が様式（Excel・Word）と記入例を公開しています。個人事業主が作るときは、公庫の様式の構成と記入手順に沿い、そこに予定納税・確定申告・消費税の納付月と生活費の引き出しを書き足すと、実際の口座残高に近い見通しになります。

この記事では、公庫の様式と記入例に書かれている内容をそのまま示したうえで、個人事業主向けに行を足した当サイトの書式（公的な様式ではありません）と、仮定の数字を使った記入例を掲載します。税金の納期限は、国税庁が公表している日付の順に記載しています。

## 公庫の資金繰り表の構成

日本政策金融公庫の「各種書式ダウンロード（小規模事業者）」のページでは、「資金繰り計画を策定する場合に、ご記入いただくもの」として、資金繰り表、資金繰り表（簡易版）、資金繰り表（記入例）が公開されています（[日本政策金融公庫 各種書式ダウンロード](https://www.jfc.go.jp/n/service/dl_kokumin.html)・2026年11月16日確認）。

資金繰り表（Excel）を開くと、次の行で構成されています（2026年11月16日に様式ファイルで確認）。

| 区分 | 行（公庫の様式の項目名） |
|------|------|
| 参考 | 売上高、（参考）前年同月の売上高 |
| 繰越 | 前月繰越金（A） |
| 経常収支・収入 | 現金売上、売掛金回収、受取手形入金・割引 → 計（B） |
| 経常収支・支出 | 現金仕入、買掛金支払、手形決済、外注加工費、人件費、諸経費、支払利息（簡易版にはなし） → 計（C） |
| 差引 | 差引過不足（B）−（C）＝（D） |
| 経常外収支 | 経常外収入、経常外支出 → 計（E） |
| 財務収支 | 収入：借入金（当公庫）、借入金／支出：借入金返済（短期）、借入金返済（長期）→ 財務収支計（F） |
| 繰越 | 翌月繰越金（A）＋（D）＋（E）＋（F）＝（G） |
| 根拠 | 売上高、売上原価、経費等の算出根拠 |

月の欄は、通常版が〔実績〕1か月と〔予定〕11か月、簡易版が〔実績〕1か月と〔予定〕6か月で、どちらにも合計と月平均の欄があります。簡易版には「（単位：千円）」と表示されています。どちらの様式にも「この書類に代わる資料を作成されていれば、そちらをご提出いただいてもかまいません。」と書かれています。普段使っている会計ソフトの資金繰り表がある場合は、それを出す選択肢もあるということです。

記入例のPDFは、〔実績〕1か月と〔予定〕3か月の欄で書かれています（[日本政策金融公庫 資金繰り表（記入例）](https://www.jfc.go.jp/n/service/pdf/sikinguri_rei.pdf)・2026年11月16日確認）。

## 公庫の記入例に書かれている手順①〜⑦

記入例のPDFには、欄ごとの書き方が手順①〜⑦として書かれています。内容を要約すると次のとおりです（出典：同上の記入例）。

| 手順 | 記入する欄 | 記入例に書かれている書き方 |
|------|------|------|
| ① | 売上高 | 直近1か月分の売上高を記入する。次月以降は、確定している分、過去の実績や季節性等を考慮し、予定している売上高を月次で記入する |
| ② | 前月繰越金 | 決算書・試算表・総勘定元帳等を確認して期首の残高を記入する。個人の場合は期首の預金通帳の残高等を記入する |
| ③ | 経常収支の収入 | 前月の実績の金額を記入し、それ以降は予測売上に対する予測回収金額を月次で記入する |
| ④ | 経常収支の支出 | 前月の実績の金額を記入し、それ以降は予測仕入・外注費等の予測支出金額を月次で記入する |
| ⑤ | 経常外収支 | 投資収入や設備売却で得た収入など、投資や設備購入に伴う支出などを、前月は実績、それ以降は予定で月次に記入する |
| ⑥ | 財務収支 | 返済予定表等から借入予定金額・支払予定金額を月次で記入する。新規で借りる予定の分の支払金額も同様に記入する |
| ⑦ | 算出根拠 | 売上高、経常収支、経常外収支等の欄に記入した金額の算出根拠を記載する |

この中で、資金繰り表を損益の表と分けているのが手順③です。売上高（①）は売上を立てた月で書きますが、収入の「売掛金回収」は、実際に入金される月で書きます。取引先ごとの締め日と支払日（例：月末締め翌月末払い）を確認し、売上の月から何か月後に入金されるかを決めてから数字を置きます。

⑦の算出根拠は、表の数字がどこから来たかを第三者に説明する欄です。「A社：月末締め翌々月10日払い・前年同月の実績をもとに見込み」のように、取引先と前提を書いておくと、自分で見直すときにも役立ちます。

## 個人事業主が書き足す行：税金の納期限

公庫の様式には税金の専用の行がありません。個人事業主の資金繰りで額が大きくなりやすいのは所得税と消費税の納付で、納期限は国税庁が毎年公表しています。令和8年（2026年）分は次のとおりです（[国税庁「主な国税の納期限（法定納期限）及び振替日」](https://www.nta.go.jp/taxes/nozei/nofu/24200042/noufu_kigen.htm)・2026年11月16日確認）。

| 税目・区分 | 納期限 | 振替納税の振替日 |
|------|------|------|
| 所得税 予定納税 第1期 | 2026年7月31日（金） | 2026年7月31日（金） |
| 所得税 予定納税 第2期 | 2026年11月30日（月） | 2026年11月30日（月） |
| 所得税 確定申告 | 2027年3月15日（月） | 2027年4月23日（金） |
| 所得税 確定申告延納 | 2027年5月31日（月） | 2027年5月31日（月） |
| 消費税及び地方消費税（個人事業者）確定申告 | 2027年3月31日（水） | 2027年4月30日（金） |

振替納税を使うと、確定申告分の引落しは納期限より後の4月になります。資金繰り表には、実際に口座から出ていく月（振替日の月）で書きます。

### 予定納税がある人・ない人

国税庁のタックスアンサーでは、予定納税は、その年の5月15日現在で確定している前年分の所得金額や税額などから計算した予定納税基準額が15万円以上となる方が対象で、原則として予定納税基準額の3分の1ずつを第1期分（7月1日〜7月31日）と第2期分（11月1日〜11月30日）に納めると説明されています（[国税庁 No.2040 予定納税](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2040.htm)・2026年11月16日確認）。

前年の所得が増えた年は、翌年の7月と11月に予定納税の支出が加わり、翌々年の3月（振替なら4月）の確定申告分と合わせて、所得税の支出が年3回になります。前年分の申告納税額が分かった時点で、7月・11月の行に3分の1ずつ入れておきます。

### 消費税を納める必要があるか

消費税は、個人事業者の場合、基準期間（その年の前々年）の課税売上高が1,000万円以下なら原則として納税義務が免除されます。ただし、適格請求書発行事業者の登録を受けている場合や、特定期間（前年の1月1日〜6月30日）の課税売上高が1,000万円を超える場合などは免除されません（[国税庁 No.6501 納税義務の免除](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6501.htm)・2026年11月16日確認）。インボイスの登録をしている場合は、売上の規模にかかわらず3月（振替なら4月）の消費税の支出を入れておきます。

### 従業員がいる場合の源泉所得税

給与から預かった源泉所得税は、原則として支払った月の翌月10日が納期限で、納期の特例の承認を受けている場合は1月〜6月分が7月10日、7月〜12月分が翌年1月20日です（国税庁・同上の納期限のページ）。特例を受けている場合は、7月と1月にまとまった支出になります。

## 個人事業主向けに行を足した資金繰り表（当サイトの書式）

次の表は、公庫の様式の構成をもとに、個人事業主の口座の動きに合わせて行を足した当サイト独自の書式です。公的な様式ではありません。公庫に出す場合は、公庫の様式に書き写すか、この表を「代わる資料」として出せるかを窓口に確認してください。

| 区分 | 行 | 公庫の様式との対応 |
|------|------|------|
| 繰越 | 前月繰越金（事業用口座の残高＋手元現金） | 前月繰越金（A） |
| 収入 | 現金・カードでの売上の入金 | 現金売上 |
| 収入 | 売掛金回収（取引先ごとに1行） | 売掛金回収 |
| 収入 | ファクタリングによる入金 | 様式に専用の行なし（下の説明を参照） |
| 支出 | 仕入・外注費 | 現金仕入・買掛金支払・外注加工費 |
| 支出 | 人件費 | 人件費 |
| 支出 | 家賃・通信費などの固定費 | 諸経費 |
| 支出 | 税金（予定納税・確定申告・消費税・源泉所得税） | 様式に専用の行なし |
| 支出 | 事業主貸（生活費の引き出し） | 様式に専用の行なし |
| 差引 | 収入計−支出計 | 差引過不足（D） |
| 財務 | 借入れ／借入金の返済 | 財務収支（F） |
| 繰越 | 翌月繰越金 | 翌月繰越金（G） |

個人事業主は、事業用の口座から生活費を引き出すため、「事業主貸」の行を入れないと、表の残高が実際の口座残高より多く見えます。

### 売掛金を売った場合の書き方（当サイトの整理）

ファクタリングで売掛金を売った場合は、資金繰り表の上では次のように書くと、実際の口座の動きと合います。

- 売った月：「ファクタリングによる入金」の行に、手数料を差し引いた受取額を入れる
- 売掛金の入金予定月（売掛先に知らせない2社間の場合）：売掛先からの入金はいったん自分の口座に入るため「売掛金回収」の行はそのまま残し、同じ額をファクタリング会社への支払いとして支出に入れる
- 売掛金の入金予定月（売掛先の承諾を得る3社間の場合）：売掛先はファクタリング会社に直接支払うため、その月の「売掛金回収」の行から外す

どちらの場合も、売った月の残高は増えますが、入金予定月の手元に残る額は売掛金の額面より少なくなります。売った後の月の行まで書き直してから判断します。2社間・3社間の違いは[ファクタリングの2社間と3社間の違い](/articles/article-factoring-2sha-3sha/)を参照してください。

## 記入例（仮定の数字）

例：単位は万円。取引先A社からは毎月60万円、B社からは10月に30万円の入金予定。前年分の所得税から計算した予定納税の第2期分が20万円。借入金の返済が毎月5万円。

| 行 | 9月 | 10月 | 11月 |
|------|------|------|------|
| 前月繰越金 | 40 | 22 | 34 |
| 売掛金回収（A社） | 60 | 60 | 60 |
| 売掛金回収（B社） | 0 | 30 | 0 |
| 収入計 | 60 | 90 | 60 |
| 外注費 | 25 | 25 | 25 |
| 家賃 | 10 | 10 | 10 |
| 諸経費 | 8 | 8 | 8 |
| 税金（予定納税 第2期） | 0 | 0 | 20 |
| 事業主貸（生活費） | 30 | 30 | 30 |
| 支出計 | 73 | 73 | 93 |
| 差引 | −13 | 17 | −33 |
| 借入金の返済 | 5 | 5 | 5 |
| 翌月繰越金 | 22 | 34 | −4 |

この例では、11月に予定納税の支出が加わることで、翌月繰越金がマイナス4万円になります。9月の時点でこの表を作っていれば、2か月前に不足が分かります。

例：12月に入金予定のA社の売掛金60万円を、11月に手数料10%で売る場合、11月の「ファクタリングによる入金」は54万円で、11月の翌月繰越金は50万円になります。一方、12月はA社の60万円がそのまま手元に残らなくなるため（2社間なら入金後にファクタリング会社へ支払う）、12月の行を書き直して、12月に新たな不足が出ないかを確認します。

この例では、不足額が4万円と小さいため、売掛金の一部だけを売る、支払日をずらす相談をする、小規模企業共済の貸付を使う、といった方法とも比べられます。共済の貸付の条件は[個人事業主がお金を借りる先の違い](/articles/article-kojin-okane-kariru/)、手元の書類から方法を選ぶ手順は[個人事業主の資金調達](/articles/article-kojin-shikin-chotatsu/)にまとめています。

## よくある質問

**Q: 公庫に出す資金繰り表は、公庫の様式でなければいけませんか？**

A: 公庫の資金繰り表の様式には「この書類に代わる資料を作成されていれば、そちらをご提出いただいてもかまいません。」と書かれています。会計ソフトなどで作った資金繰り表がある場合は、それを出せるかを申込み先に確認してください。

**Q: 何か月先まで作ればよいですか？**

A: 公庫の様式は、通常版が実績1か月と予定11か月、簡易版が実績1か月と予定6か月の欄で作られています。予定納税（7月・11月）や確定申告分（3月、振替納税なら4月）の支出を入れるには、該当する月まで延ばして作ります。

**Q: 予定納税の支出は、誰でも入れる必要がありますか？**

A: 国税庁の説明では、予定納税の対象は、5月15日現在で確定している前年分の所得金額や税額などから計算した予定納税基準額が15万円以上となる方です。対象の方には、所轄の税務署長からその年の6月15日までに、書面またはe-Taxで予定納税額が通知されると案内されています。

**Q: 売上が増えているのに、資金繰り表ではお金が減っていきます。なぜですか？**

A: 売上高は売上を立てた月で、売掛金回収は実際に入金される月で書くためです。取引先への支払日より前に外注費や仕入の支払いがある場合、売上が増えるほど先に出ていくお金が増えます。売掛金の入金を早める方法は[ファクタリングで資金繰りを改善する方法](/articles/article-factoring-shikinguri/)で扱っています。

## まとめ

1. 日本政策金融公庫が資金繰り表の様式（通常版・簡易版）と記入例を公開している。構成は経常収支・経常外収支・財務収支と、前月繰越金・翌月繰越金
2. 記入例の手順①〜⑦に沿い、売掛金は入金される月で書き、⑦に算出根拠を残す
3. 個人事業主は、税金（予定納税7月・11月、確定申告3月または振替の4月、消費税）と事業主貸の行を足す
4. 売掛金を売る場合は、売った月の入金と、入金予定月の扱い（2社間・3社間で異なる）を両方書き直す
